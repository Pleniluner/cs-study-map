## 一、从纸笔状态表到变量与顺序执行

本章的程序使用整数和简单文本。整数在这里不受第一章无符号 16 位范围限制；Python 变量也不是第二章玩具机器里指定地址的寄存器。先把变量名看成贴在某个值上的标签：x = 4 让名字 x 指向整数 4。语句 x = x + 3 先用旧 x 算出 7，再让 x 指向 7。等号表示一次赋值操作，不是在证明旧值与新值相等。

顺序执行意味着后面的语句读取前面已经更新过的状态。下面先令 x 为 4，再让 y 指向 x 当前的整数，最后重新给 x 赋值。结束时 x 为 7、y 为 4。这里变化的是 x 的绑定；整数本身没有被原地修改。现在只使用整数，不能把这种现象推广成“所有对象在赋值时都会复制”；后续学习列表时会再讨论共享对象。

print(x, y) 是调用已有的打印功能，把两个当前值写到屏幕，默认中间隔一个空格，末尾换行。圆括号围住本次要显示的值，逗号分隔它们。引号包住的是文本，例如 print("done") 显示 done；不带引号的 x 表示读取变量。井号开始的注释帮助人阅读，不参与计算。

本章用英文名字减少输入负担：total 表示总量，count 表示次数，remaining 表示剩余量。名字要先赋值再使用，大小写不同会被当成不同名字。把代码保存成一个文件时，应完整复制代码块，不要把后面的预期输出也放进程序。独立代码块之间不共享上一次运行的变量。

**完整程序**

```python
x = 4
y = x
x = x + 3
print(x, y)
```

**预期输出**

```text
7 4
```

## 二、条件与分支：本次究竟走哪条路

赋值负责改变状态，比较负责提出一个能回答真或假的问题。Python 用两个等号判断相等，用感叹号接等号判断不等；大于、小于和带等号的比较符号用于检查范围。比较得到 True 或 False，分别表示真和假。一个等号不能在这里代替相等比较。代码中的比较符号请按原样输入，注意使用英文标点。

if 后面写条件，冒号之后的下一行开始一个缩进块。本书统一缩进四个空格。同一层的语句向左对齐，属于该分支的语句整体向右缩进；回到左侧的语句已经离开分支。缩进决定哪些操作受条件控制，不只是排版。else 后面不再写条件，它表示前面条件都没有满足时执行的部分。

多个互斥情况可以用 if、elif、else 连成一条链。程序从上到下检查，执行第一个条件为真的块，然后跳过这条链剩余的分支。下面规定一个虚构的温度标签规则：至少 30 标为 hot，否则至少 15 标为 mild，其余标为 cool。20 先未达到 30，再满足至少 15，因此只输出 mild。条件的次序要与规则一致；若先判断至少 15，30 也会提前进入这个范围。

几个独立的 if 则会分别判断，可能执行多个块，不能自动当成互斥分支。复杂条件中的 and 要求两边都为真，or 要求至少一边为真；本章只组合简单比较。设计分支后，拿每个分界值本身、紧邻的较小值和较大值核对一次，检查是否有遗漏、重叠或次序错误。

**完整程序**

```python
temperature = 20
if temperature >= 30:
    print("hot")
elif temperature >= 15:
    print("mild")
else:
    print("cool")
```

**预期输出**

```text
mild
```

## 三、while：条件仍成立就再做一轮

while 适合表达“只要条件成立，就继续处理”。它先检查条件；为真才执行一轮缩进块，执行完回到条件处重新判断；为假就继续执行循环之后的语句。因此循环可能一次也不执行。不要先入为主地认为循环体至少会运行一次，初始状态也是条件判断的对象。

下面有 11 个单位，每轮必须完整取走 3 个。remaining 记录剩余量，rounds 记录已成功取走的轮数。循环前设置 remaining 为 11、rounds 为 0；条件要求剩余量至少为 3。三轮后的状态依次是剩 8、取 1 轮；剩 5、取 2 轮；剩 2、取 3 轮。再次检查时 2 不足 3，退出并输出 3 2。

一个能解释清楚的循环需要三件事：开始前的初始化、每轮执行的动作、让条件最终不再成立的进展。这里每次成功循环都减少 3 个单位，剩余量不会变负；对于给定的非负整数初值，能执行的轮数有限。若忘记更新 remaining，条件就会一直保持真，程序不会自动知道你已经处理过一轮。

再检查边界：初值为 0 或 2 时，成功轮数应为 0；初值为 3 时，恰好执行一轮并剩 0。判断应当包含“等于 3”，否则会漏掉最后一个完整批次。rounds 必须在循环外初始化；若每轮都重新赋成 0，计数就无法积累。修改循环时应先重新推演这些最小情形，再尝试大数。

**完整程序**

```python
remaining = 11
rounds = 0
while remaining >= 3:
    remaining = remaining - 3
    rounds = rounds + 1
print(rounds, remaining)
```

**预期输出**

```text
3 2
```

## 四、for 与 range：逐个处理有限编号

如果任务是依次检查一批已知编号，for 通常更直接。for number in range(1, 8) 表示依次把 1 到 7 交给名字 number，每取得一个数就执行一轮循环体。range 的右端点 8 不会被取到；单参数 range(4) 则依次给出 0、1、2、3。这里把 range 看成提供整数序列的规则即可，它本身不是把所有整数预先装进一个列表。

本章只使用默认步长为 1 的形式。起点等于或大于终点时，这种 range 不提供任何数，例如 range(3, 3) 是空的。要处理包含上界 n 的编号 1 到 n，就写 range(1, n + 1)。这与半开区间的边界观念相近，但这里是在提供整数，不是在分配内存。

for 负责依次取得下一个值，不需要在循环尾手动把 number 加一。循环体里即使重新给 number 赋值，也不会改变 range 接下来提供什么数。下面用余数运算符 % 检查偶数：整数除以 2 余数为 0，就符合条件。比如 7 % 2 为 1，8 % 2 为 0；本章的除数总为正整数。

编号 1 到 7 中只有 2、4、6 符合条件。count 每遇到一个符合项增加 1，total 加上该项的数值，所以最后是 3 和 12。注意 if 缩进在 for 里面，两个更新又缩进在 if 里面；最后的 print 回到最左侧，只在循环全部结束后执行一次。计数与求和是两个不同状态，不能都简单写成加一。

**完整程序**

```python
count = 0
total = 0
for number in range(1, 8):
    if number % 2 == 0:
        count = count + 1
        total = total + number
print(count, total)
```

**预期输出**

```text
3 12
```

## 五、用状态含义和边界检查循环

运行结果与预期一样是有用的证据，但还需要解释结果为何成立。先给每个状态变量写一句含义。例如要累加 1 到 n，令 number 是下一项，total 是已经加过的项之和。循环前 number 为 1、total 为 0，表示还没有加任何项；空的和约定为 0。这一句含义把初始化和后面的更新连接了起来。

下面每轮先把 number 加进 total，再把 number 增加 1。于是每轮开始时，total 都恰好是 1 到 number 减 1 的和。这个在循环推进中一直保持的关系叫循环不变式，不是说变量数值始终不变。对于 n 为 4，轮首状态依次为数 1、和 0；数 2、和 1；数 3、和 3；数 4、和 6；退出时数 5、和 10。

终止条件与不变式一起说明答案：退出时 number 已经超过 n。n 至少为 1 时，number 此前每轮只增加 1，最后加过的项正好是 n；n 为 0 时没有加过任何项。循环为什么会结束也要单独回答：n 固定为非负整数，number 从 1 开始，每轮持续增加，必定越过 n。说明“和一直正确”不能代替说明“循环一定停止”。

最小测试通常比随意选大数更容易暴露错误。n 为 0 时没有项，输出应为 1 和 0；n 为 1 时只加一次，输出 2 和 1。如果先增加 number 再累加，就会漏掉 1 并多加最后一项。若实际输出不符，从第一轮状态差异向前检查初始化、条件和语句顺序，不要只修饰最后的打印结果。本章把这种逐步核对方法继续用于后面的函数。

**完整程序**

```python
n = 4
number = 1
total = 0
while number <= n:
    total = total + number
    number = number + 1
print(number, total)
```

**预期输出**

```text
5 10
```

## 跟着做：原创例题

### 例题 1

设计一个虚构活动的分组标签程序。人数 participants 为非负整数：0 人输出 empty；1 到 8 人输出 small；9 人及以上输出 large。当前人数为 8。按条件检查顺序说明输出，并检查人数改为 0、1、9 时是否仍符合规则。

1. 先列出三个互斥范围：只有 0；从 1 到 8；至少 9。输入已经约定非负，不额外处理负数。
2. 先判断人数是否等于 0。当前 8 不等于 0，不执行第一个块。
3. 再判断人数是否不超过 8。已排除 0，当前 8 满足条件，执行 small 的打印。
4. 这是同一条分支链，选中第二块后不再执行 else；当前程序只输出一行。
5. 独立核对边界：0 在第一块得到 empty，1 和 8 在第二块得到 small，9 在最后一块得到 large。

**结果与核对**

participants 为 8 时输出 small。0、1、8、9 的标签依次为 empty、small、small、large。若把第二个判断改成严格小于 8，会把 8 错分到 large；若写成三个互不关联的 if，还需要额外保证各条件互斥。

**完整程序**

```python
participants = 8
if participants == 0:
    print("empty")
elif participants <= 8:
    print("small")
else:
    print("large")
```

**预期输出**

```text
small
```


### 例题 2

一个纸笔练习计划规定第 1 天完成 1 个练习，第 2 天完成 2 个，第 3 天完成 3 个，以此类推。目标 target 是非负整数。求累计数量首次达到或超过 20 时的天数与累计量，并解释为什么前一天还没达到。目标为 0 时应如何处理？

1. 用 days 记录已经完成的天数，total 记录这些天的练习总量；开始时均为 0。
2. 循环条件是累计量仍小于目标。进入一轮后先把天数增加 1，再把当天数量加进累计量。
3. 前四轮的天数与累计量依次为 1 与 1、2 与 3、3 与 6、4 与 10。
4. 第五轮后累计为 15，仍小于 20；第六轮后累计为 21，下一次判断不再成立。
5. 因为每天增加的数量均为正，累计量严格增加；退出时的第 6 天是第一次达到目标，前一天仅为 15。
6. 目标为 0 时，初始累计已经达到目标，循环执行零轮，答案为 0 天、0 个。

**结果与核对**

目标 20 对应 6 天、累计 21；1+2+3+4+5=15 不足，补上第 6 天的 6 个得到 21。输出中的超过目标是允许的，因为题目要求达到或超过。只等待累计量恰好等于 20 是错误条件，这个增长序列会跨过 20。

**完整程序**

```python
target = 20
days = 0
total = 0
while total < target:
    days = days + 1
    total = total + days
print(days, total)
```

**预期输出**

```text
6 21
```

upper = 20

### 练习 3

有 23 个待处理物件，每批最多处理 5 个，最后不足 5 个也处理为一批。用 while 模拟，输出批次数和最终剩余量；不允许让剩余量变负。分别检查初始数量为 0、1、5、6 的结果，并说明循环为何终止。

<details>
<summary>提示</summary>

只在还有剩余物件时进入循环。剩余至少 5 就减 5，否则把最后不足一批的剩余设为 0；每成功处理一批再计数。

</details>

<details>
<summary>解答与检查</summary>

23 的剩余量依次变为 18、13、8、3、0，共 5 批，输出 5 0。初始 0、1、5、6 分别需要 0、1、1、2 批，最终均剩 0。每轮都把正的剩余量减少，最后一轮清零，因而会停止。若循环条件允许剩余等于零也进入，清零后仍可能一直重复。

**完整程序**

```python
remaining = 23
capacity = 5
batches = 0
while remaining > 0:
    if remaining >= capacity:
        remaining = remaining - capacity
    else:
        remaining = 0
    batches = batches + 1
print(batches, remaining)
```

**预期输出**

```text
5 0
```


</details>

<a id="pitfalls"></a>

## 容易混淆的地方

- **把赋值写成相等判断，或认为赋值语句同时约束旧值和新值。** 赋值先算右侧再更新左侧名字；相等比较产生真假结果。先在纸上写旧状态和新状态，再判断自己需要哪种操作。
- **忽略缩进，把本应每轮执行的更新写到循环外。** 四个空格决定该语句属于哪个块。若条件依赖的变量在循环体里不变，while 可能一直无法退出。
- **以为 range 的右端点会被处理，或者以为循环至少执行一次。** 默认正步长的 range 不含右端点，while 会先检查条件。用空范围和初值已经满足停止条件的情况核对零次执行。
- **只看总和是否合理，没有检查第一次、最后一次和停止原因。** 说明状态含义，再核对每轮更新保持它；另外证明条件终将变假。两种检查分别帮助发现算错与停不下来。
