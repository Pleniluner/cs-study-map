# 给自己的计算机入门教材

[项目说明](../../README.md) · [资料地图](../index.md) · [记录自己的学习](../learning-log-template.md)

目标是给自己一条能学下去的路线：读讲解 → 跟例题 → 独立做题 → 用自测找出卡点 → 回到资料深入。课程目录为选材提供线索，章节按先修关系组织。

已登记的具体章节中，可试学 33 章，待复核 0 章，待编写 0 章。后续待写方向另列于下方，尚未计入具体章节数量。每章含讲解、2 个原创例题、3 道练习及解答。当前章节均为 AI 初稿，尚未经过学科专家或学习者实际试学验收。

## 从这里开始

先按下表顺序阅读。能独立解释并做对自测再前进；卡住时在本机学习记录中写下具体问题，后续据此调整教材。

- 算法分析与理论：递推式、摊还证明、随机化、排序下界与复杂度入门

- 计算机组成与操作系统：补码、浮点、缓存、虚拟地址、页表、TLB、进程线程与文件系统
- 计算机网络、数据库、数学基础与编译原理（按先修关系逐批细化）

## 更新怎样影响教材

同步先比较来源内容，变化会使旧导读失效。教材记录使用的分析版本；来源分析、编写范围或生成规则改变后会标为待复核。只有拿到有效资料分析后，写作命令才会按既定计划生成新稿。原资料不会并入教材仓库。
