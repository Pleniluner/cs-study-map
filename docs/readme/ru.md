Проект прежде всего предназначен для самостоятельного обучения сопровождающего. Он выбирает темы из [REKCARC-TSC-UHT](https://github.com/PKUanonym/REKCARC-TSC-UHT), перестраивает их в учебник на китайском языке с учетом предварительных знаний и добавляет объяснения, авторские примеры, упражнения с решениями и самопроверку. Синхронизация, классификация ИИ и путеводители помогают выбирать и обновлять материал.

**[Учебник](../textbook/index.md)** · [Карта знаний](../index.md) · [Охват](../status.md) · [Использование](../usage.md) · [Источники и лицензии](../../ATTRIBUTION.md)

Это личный учебный проект Pleniluner, официально не связанный с Университетом Цинхуа или сопровождающими исходного проекта. Публичный репозиторий содержит авторские инструменты, черновики учебника, указатели источников и материалы ИИ. Исходные учебники, слайды, задания, код студентов и полный извлеченный текст не публикуются.

Главы 4–9 используют Python 3.11 или новее и содержат 60 самостоятельных программ с ожидаемым выводом. Подготовка и порядок занятий описаны в [руководстве по практике программирования](../programming-practice.md) и [руководстве по структурам данных](../data-structures-practice.md), оба на китайском языке.

Каждая глава содержит подробные объяснения, 2 авторских примера, 3 упражнения с раскрывающимися решениями, самопроверку и источники тем. Это первый черновик ИИ, без экспертного рецензирования и апробации учащимися. Наличие этих глав не означает, что учебник готов для каждого курса.

## Возможности

Учитесь по главам и храните личные записи в `.local/`, исключённом из Git. Создавайте авторские главы по выявленным темам с фиксацией версий источников. Ищите материалы по области, курсу или теме, выявленной ИИ, и открывайте закреплённую версию источника. Проверяйте темы, предварительные знания, рекомендации и места подтверждения; повторно используйте неизменившийся анализ и исправляйте автоматическую классификацию ручными правилами.

Материалы ИИ указывают охват извлечения, модель и отсутствие ручной проверки. Полнота каталога и охват материалами ИИ учитываются отдельно. Частичное извлечение, неподдерживаемые форматы и ошибки отображаются явно.

## Быстрый старт

Требуется Python 3.11 или новее. Эти шаги получают метаданные и строят навигацию; ключ модели не нужен, содержимое источников не скачивается.

```bash
git clone https://github.com/Pleniluner/cs-study-map.git
cd cs-study-map
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows PowerShell:
# .\.venv\Scripts\Activate.ps1
python -m pip install -e .
cs-study-map run --limit 0
```

## Работа ИИ

Оба режима используют одинаковую проверку и генерацию материалов. Для API задайте `CS_STUDY_API_BASE`, `CS_STUDY_MODEL` и `CS_STUDY_API_KEY`. Для локального Codex CLI задайте `CS_STUDY_PROVIDER=codex` и `CS_STUDY_MODEL`, при необходимости — `CS_STUDY_CODEX_BIN`. API поддерживает Chat Completions и Responses: по умолчанию используется `chat`, а `CS_STUDY_API_STYLE=responses` включает Responses. Выбирайте модель, поддерживаемую сервисом. Версия Codex CLI также должна поддерживать выбранную модель; учётными данными управляет сам CLI.

```bash
cs-study-map analyze --course 程序设计基础 --limit 2 --require-ai
cs-study-map write --limit 1 --require-ai
cs-study-map build
cs-study-map validate
```

Настройка, примеры PowerShell и параметры GitHub описаны в [руководстве по использованию](../usage.md).

## Плановая синхронизация

GitHub Actions проверяет источники ежедневно; **Sync study map** можно запустить вручную. При настроенной модели процесс создаёт материалы и главы в пределах бюджета, проверяет их и сохраняет изменения коммитом. По умолчанию за день анализируется не более 6 материалов и пишется 1 глава. Область работы задаётся в `config/curriculum.json`.

Без модели каталог всё равно синхронизируется со статусом `not-configured`. Готовые материалы доступны, а изменившиеся источники ожидают анализа. Правила по именам файлов и имитационные результаты не выдаются за выполненную работу ИИ. Для чтения карты аккаунт модели не нужен. Форки требуют собственной настройки API; локальная авторизация Codex не загружается на GitHub. После длительного бездействия GitHub может отключить расписание; его можно включить в Actions.

## Структура проекта

```text
config/                  маршруты, источники, классификация, соответствия и исправления
catalog/                 метаданные, анализ, черновики и охват
docs/textbook/           Учебник на GitHub (сейчас на китайском)
docs/                    Навигация по курсам и областям, шаблон заметок, справка
src/cs_study_map/        синхронизация, извлечение, классификация ИИ и написание
tests/                   проверки синхронизации, восстановления, происхождения и публикации
.github/workflows/       синхронизация по расписанию и непрерывная интеграция
.cache/                  Локальные файлы и кэш извлечения; не коммитить
.local/                  Личные заметки; не коммитить
```

Перевод README не означает перевода самого учебника: его текст сейчас на китайском языке.

Начальные соответствия областей взяты из личной организации курсов сопровождающим и допускают исправления. Это не официальная классификация исходного проекта и не университетский учебный план. Новые курсы ожидают классификации. Поддерживаются текст, распространённый исходный код, PDF с извлекаемым текстом, DOCX, PPTX и Notebook. OCR сканов, старые DOC/PPT и анализ архивов не реализованы. По умолчанию из PDF извлекается не более 8 страниц и 10 000 символов, поэтому длинный материал может быть прочитан лишь частично.

## Проверка и вклад

Выполните `python -m unittest discover -s tests -v` и `cs-study-map validate --tracked`. Сообщайте об ошибках через Issues. PR могут улучшать код, соответствия и ручные правила; см. [руководство для участников](../../CONTRIBUTING.md).

Авторские программы, текст учебника и документация сопровождения распространяются по лицензии MIT. Права на исходные материалы не меняются; см. [источники и лицензии](../../ATTRIBUTION.md).
