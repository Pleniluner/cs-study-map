## ما الذي يتيحه المشروع

ادرس بحسب الفصول واحفظ ملاحظاتك الخاصة في `.local/` الذي يتجاهله Git. أنشئ فصولًا أصلية من الموضوعات المحددة مع تسجيل إصدارات المصادر. ابحث بحسب المجال أو المقرر أو الموضوع الذي حدده الذكاء الاصطناعي، وافتح نسخة ثابتة من المصدر. راجع الموضوعات والمتطلبات السابقة والاقتراحات ومواضع الأدلة، وأعد استخدام التحليلات التي لم تتغير وصحح التصنيف التلقائي بقواعد يدوية.

توضح أدلة الذكاء الاصطناعي نطاق الاستخراج والنموذج وحالة عدم المراجعة البشرية. يُقاس اكتمال الفهرس وتغطية الأدلة كلٌّ على حدة، مع إظهار الاستخراج الجزئي والصيغ غير المدعومة وحالات الفشل.

## البدء السريع

يلزم Python 3.11 أو أحدث. تجلب الخطوات التالية البيانات الوصفية وتبني التنقل، دون مفتاح نموذج ودون تنزيل محتوى المصادر.

```bash
git clone https://github.com/Pleniluner/cs-study-map.git
cd cs-study-map
python -m venv .venv
# Linux / macOS:
source .venv/bin/activate
# Windows PowerShell:
# .\.venv\Scripts\Activate.ps1
python -m pip install -e .
cs-study-map run --limit 0
```

## تشغيل الذكاء الاصطناعي

يستخدم النمطان مسار التحقق وتوليد الأدلة نفسه. لواجهة API اضبط `CS_STUDY_API_BASE` و`CS_STUDY_MODEL` و`CS_STUDY_API_KEY`. ولـ Codex CLI المحلي اضبط `CS_STUDY_PROVIDER=codex` و`CS_STUDY_MODEL`، ويمكن تحديد `CS_STUDY_CODEX_BIN`. تدعم الواجهة Chat Completions وResponses؛ الافتراضي هو `chat` ويختار `CS_STUDY_API_STYLE=responses` نمط Responses. اختر نموذجًا تدعمه الخدمة. يجب أن يدعم إصدار Codex CLI النموذج المختار، وهو يدير بيانات اعتماده بنفسه.

```bash
cs-study-map analyze --course 程序设计基础 --limit 2 --require-ai
cs-study-map write --limit 1 --require-ai
cs-study-map build
cs-study-map validate
```

راجع [دليل الاستخدام](../usage.md) للإعداد وأمثلة PowerShell وإعدادات GitHub.

## المزامنة المجدولة

يفحص GitHub Actions المصادر يوميًا، ويمكن تشغيل **Sync study map** يدويًا. عند إعداد نموذج، يُنشئ الأدلة والفصول ضمن الميزانية ثم يتحقق منها ويسجل التحديثات. الحد الافتراضي اليومي هو تحليل 6 مواد وكتابة فصل واحد؛ ويُحدد النطاق في `config/curriculum.json`.

دون نموذج تستمر مزامنة الفهرس وتظهر الحالة `not-configured`. تبقى الأدلة السابقة متاحة وتنتظر المصادر المعدلة التحليل. لا تُعرض قواعد أسماء الملفات أو المخرجات المحاكية بوصفها عملًا مكتملًا للذكاء الاصطناعي. لا يتطلب تصفح الخريطة حساب نموذج. تحتاج النسخ المتفرعة إلى إعداد API خاص بها، ولا يُرفع تسجيل الدخول المحلي لـ Codex إلى GitHub. قد يعطل GitHub الجدولة بعد خمول طويل؛ ويمكن تفعيلها من Actions.

## بنية المشروع

```text
config/                  مسارات التعلّم والمصادر والتصنيف وربط المقررات والتصحيحات
catalog/                 البيانات الوصفية والتحليلات والمسودات والتغطية
docs/textbook/           كتاب متاح للقراءة على GitHub (بالصينية حاليًا)
docs/                    التنقل بين المقررات والمجالات وقالب سجل التعلّم ودليل الاستخدام
src/cs_study_map/        المزامنة والاستخراج والتصنيف والكتابة بالذكاء الاصطناعي
tests/                   فحوص المزامنة والاستعادة والمصادر والنشر
.github/workflows/       المزامنة المجدولة والتكامل المستمر
.cache/                  ملفات المصدر المحلية وذاكرة الاستخراج؛ لا تُرسل
.local/                  ملاحظات التعلّم الخاصة؛ لا تُرسل
```

ترجمة README لا تعني ترجمة متن الكتاب؛ فالنص التعليمي الحالي بالصينية.

جاء الربط الأولي للمجالات من تنظيم شخصي للمقررات وهو قابل للتصحيح، وليس تصنيفًا رسميًا للمشروع الأصلي أو خطة جامعية. تنتظر المقررات الجديدة التصنيف. تشمل الصيغ المدعومة النصوص والشيفرات الشائعة وPDF القابل لاستخراج النص وDOCX وPPTX وNotebook. لم يُنفذ OCR للمسح الضوئي أو دعم DOC/PPT القديم أو تحليل الأرشيفات المضغوطة. يقتصر استخراج PDF افتراضيًا على 8 صفحات و10,000 محرف، لذا قد تُقرأ المادة الطويلة جزئيًا فقط.

## التحقق والمساهمة

شغّل `python -m unittest discover -s tests -v` و`cs-study-map validate --tracked`. أبلغ عن الأخطاء عبر Issues. يمكن لطلبات PR تحسين الشيفرة والربط والقواعد اليدوية؛ راجع [دليل المساهمة](../../CONTRIBUTING.md).

تستخدم البرامج الأصلية ونصوص الكتاب ووثائق الصيانة ترخيص MIT. لا تتغير حقوق مواد المصادر؛ راجع [المصادر والتراخيص](../../ATTRIBUTION.md).
