# 编程练习与运行：从纸笔追踪到 Python

[教材目录](textbook/index.md) · [第 4 章：控制结构](textbook/04-control-flow.md) · [第 5 章：函数](textbook/05-functions.md) · [学习记录模板](learning-log-template.md)

前三章用明确规定的教学模型解释数据、执行和分配。这两章开始用 Python 3.11 或更新版本表达计算：先决定哪些步骤执行、重复多少次，再把一段计算封装为函数。继续沿用“先写状态，再核对变化”的方法，同时注意 Python 的变量绑定与前面玩具机器的整数格并不完全相同。

## 准备一个能运行小程序的环境

只需 Python，无须安装第三方包，也不需要模型账号。可先在终端执行 `python --version`，确认版本为 3.11 或更新版本。若系统使用 `python3` 命令，以下命令中的 `python` 相应替换为 `python3`。只想纸笔学习时，也可以先预测输出，稍后再实际运行。

在项目目录下新建 `.local/` 文件夹，把当前一段“完整程序”复制到 `.local/lesson.py`。只复制 Python 代码框里的内容；“预期输出”用于核对，不要一起粘贴。每个程序都能独立运行，先不要把多段程序拼接到同一文件。

```bash
python .local/lesson.py
```

已经按项目说明建立虚拟环境的 Windows 读者也可直接运行：

```powershell
.\.venv\Scripts\python.exe .local/lesson.py
```

编辑器保存为 UTF-8。程序使用英文标点和每层 4 个空格的缩进，避免混用制表符与空格。示例输入直接写在变量赋值或函数调用中，运行时不会等待键盘输入。个人改写和错题过程放在 `.local/`，该目录由 Git 忽略。

## 每次练习做四件事

1. **先预测。** 暂时遮住“预期输出”，写下输入范围、变量初值以及预计打印的每一行。遇到循环就记录条件检查前的状态；遇到函数就记录实参和返回值。
2. **再运行。** 比较实际输出与预测。不同就找第一处差异：是选错分支、漏了一次更新、包含了不该包含的端点，还是把打印当成返回？
3. **改变边界。** 根据题目的输入范围，尝试零次循环、恰好命中阈值和刚刚越过阈值。每次只改输入，重新手算后运行，不要只检查题目给定的一个数。
4. **解释结果。** 说明为什么得到这个值、循环为什么能停止、函数返回给了谁。练习题先自己写完整程序，卡住时只展开提示，最后再对照折叠解答。

若出现 `SyntaxError` 或 `IndentationError`，先核对报错行及其上一行的冒号、括号和缩进。若没有报错但数值不同，按上面的方法追踪状态。若循环一直不结束，可在终端按 Ctrl+C 中止，再检查更新是否让条件逐渐变假；不要把无法停止当成程序还需要多运行一会儿。

## 两章各自要达到什么程度

| 章节 | 至少能独立做到 | 需要回读时 |
| --- | --- | --- |
| [第 4 章](textbook/04-control-flow.md) | 区分顺序、互斥分支和重复；追踪计数与累加；解释 `range` 的停止值、零次循环和终止条件 | 重做[三个练习](textbook/04-control-flow.md#practice)，分别检查零、端点和不足一批的情况 |
| [第 5 章](textbook/05-functions.md) | 说明定义与调用、形参与实参、打印与返回的区别；用局部名字组合两个函数，并验证多次调用 | 重做[三个练习](textbook/05-functions.md#practice)，检查空区间、负数端点、零目标和恰好达到目标 |

两章共有 20 段完整程序：每章 5 段讲解程序、2 个例题程序和 3 个练习参考实现。它们使用本章已解释的整数、判断、循环和函数；数组、文件输入输出、异常处理及递归留待后续。题目给定的输入范围是约定，程序不一定会主动拒绝范围外输入。
