## 本批已完成：第 25–27 章

- [x] **[第 25 章：回溯与搜索剪枝](textbook/25-backtracking.md)。** 已讲选择树、路径撤销、输出复制、位置子集、排列、组合与非负和约束剪枝；包含皇后、值去重、括号与全部简单路径，已用独立枚举核对解集、输入保持和剪枝前后的一致性。
- [x] **[第 26 章：贪心算法与正确性证明](textbook/26-greedy-algorithms.md)。** 已讲找零反例、区间调度交换论证与保持领先、最小合并及 Huffman；练习最少删除、区间选点与最大拖期，已用独立穷举核对最优值和返回方案。

## 额度使用与批次记录约定

以下是后续记录规范，尚未建立请求用量与费用台账。本批已记录教材、测试和运行验收，未据此估算模型费用。申请所需资源将用于统一验证报告、诊断与用量记录、后续代码和教材维护及必要的选材分析，优先推进上述 B 阶段。

| 每批需要记录 | 记录要求 |
| --- | --- |
| 工作范围与基线 | 任务、开始时的提交、预计修改对象和可验收结果；执行前设定该批调用数量或可用金额上限 |
| 实际调用 | 日期、模型、用途、成功或失败状态、服务返回的输入与输出用量；人工重试关联到前一次尝试，超时不推断为未计费 |
| 费用与未知值 | 费用以实际账单或可核对的计价依据为准；缺失用量或账单时注明未知，不填零，也不把 token 数直接当作金额 |
| 验收结果 | 对应提交、CI、已验收章节或修复、仍存在的问题；生成次数与验收通过数分别统计 |
| 公开摘要 | 公布工作、累计用量的可核验摘要及结果链接；原始账单、账号信息、凭据和个人记录留在本机 |

首个采用用量记录的批次用于取得真实的调用和返工数据，再估计后续范围。尚无实测时不承诺完成整套课程，也不声称已经降低成本。达到批次上限或出现持续失败时保留已验收结果、记录未完成项，再调整下一批安排。

规划条目只有在交付物可用且检查完成后才能勾选；模型生成完成、请求耗尽或写出提纲都不单独构成完成。外部使用量和社区反馈按实际证据记录，教材数量不用于替代采用度。
