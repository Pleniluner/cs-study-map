## 下一批：第 25–27 章，尚未编写

- [ ] **第 25 章：回溯与搜索剪枝。** 衔接递归、栈和 DFS，讲选择树、路径状态、选择与撤销、输出复制、可行性剪枝及完备性。拟用子集、排列、组合与约束搜索设计例题和练习；用独立枚举核对解集，检查遗漏、重复、输入保持及剪枝前后答案一致性。
- [ ] **第 26 章：贪心算法与正确性证明。** 在 Prim、Kruskal 的已有经验上，系统讲局部选择、交换论证、保持领先及反例。拟用区间调度、合并成本与 Huffman 编码组织实例；对小规模输入穷举最优值，明确哪些条件变化会使原策略失效。
- [ ] **第 27 章：动态规划入门。** 从递归中的重复子问题出发，讲记忆化、状态、转移、初始条件、计算顺序、答案恢复和空间压缩条件。拟用计数、最小费用与简单序列问题；对照朴素求解，检查不可达状态、零规模、重复转移及前后轮状态混用。

三章的共同交付标准：每章 5 节实质讲解、2 个原创例题、3 道练习与完整解答；每章 10 段自包含程序，共新增 30 段。全部程序实际执行并逐字核对输出，配套独立性质与边界检查，更新来源说明、练习指引和入口，经过双版本 CI 后发布。当前章节数仍为 24，下一批完成后目标为 27 章、240 段程序。

## 额度使用与批次记录约定

以下是后续记录规范，尚无资助额度消耗或新增交付数据。申请所需资源将用于本项目的代码改进、测试、教材程序验证及必要的选材分析，优先完成上述 A、B 阶段。

| 每批需要记录 | 记录要求 |
| --- | --- |
| 工作范围与基线 | 任务、开始时的提交、预计修改对象和可验收结果；执行前设定该批调用数量或可用金额上限 |
| 实际调用 | 日期、模型、用途、成功或失败状态、服务返回的输入与输出用量；人工重试关联到前一次尝试，超时不推断为未计费 |
| 费用与未知值 | 费用以实际账单或可核对的计价依据为准；缺失用量或账单时注明未知，不填零，也不把 token 数直接当作金额 |
| 验收结果 | 对应提交、CI、已验收章节或修复、仍存在的问题；生成次数与验收通过数分别统计 |
| 公开摘要 | 公布工作、累计用量的可核验摘要及结果链接；原始账单、账号信息、凭据和个人记录留在本机 |

第一批用于取得真实的调用和返工数据，再估计后续范围。尚无实测时不承诺完成整套课程，也不声称已经降低成本。达到批次上限或出现持续失败时保留已验收结果、记录未完成项，再调整下一批安排。

规划条目只有在交付物可用且检查完成后才能勾选；模型生成完成、请求耗尽或写出提纲都不单独构成完成。外部使用量和社区反馈按实际证据记录，教材数量不用于替代采用度。
