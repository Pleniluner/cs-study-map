# 项目概况与可复现成果

[项目首页](../README.md) · [未完成清单](roadmap.md) · [验证记录](verification.md) · [运行说明](usage.md)

更新于 2026-10-23。cs-study-map 是 Pleniluner 维护的 MIT 开源 Python 工具，首先服务维护者的中文计算机自学。它把资料版本追踪、知识点分析、原创教材编排和程序验证放在同一个可维护的仓库中。当前已有可运行工具和 24 章教材草稿，完整课程、统一验证报告与用量记录仍待建设。

## 要解决的问题与预期用途

学习资料分散、先修关系不清楚、来源更新后旧解释难以定位，是这个项目的起点。生成教材后，还需要核对例题、实际运行代码、保存修订依据，才能逐步形成可复查的学习路径。

目前的直接使用者是维护者本人。公开代码、配置、测试和原创内容，希望供中文自学者阅读，也供课程维护者复用资料整理和教材校验流程。外部采用和学习效果仍需实际反馈验证；项目与清华大学及上游资料维护者没有官方隶属关系。

## 已有软件能力与检查依据

| 能力 | 当前行为 | 可检查的代码与测试 |
| --- | --- | --- |
| 追踪资料变化 | 保存来源提交和内容标识，区分新增、修改、移动与删除；变化后使旧分析失效 | [同步实现](../src/cs_study_map/sync.py)、[更新测试](../tests/test_pipeline.py) |
| 生成有依据的导读 | 校验结构化输出和证据定位，记录提取覆盖范围；区分未配置、失败与成功 | [分析流程](../src/cs_study_map/pipeline.py)、[结果校验](../src/cs_study_map/ai.py) |
| 维护原创教材 | 从知识点摘要编排章节，保留来源和计划版本；变化后提示复核，生成失败时保留已有稿件 | [教材实现](../src/cs_study_map/textbook.py)、[教材更新测试](../tests/test_textbook_updates.py) |
| 验证教材程序 | 逐段执行已经审读的原创程序并核对输出；对算法另做边界、性质和独立参考对照 | [带权图测试示例](../tests/test_weighted_graph_lessons.py)、[验证记录](verification.md) |
| 构建与发布检查 | 重建阅读页面，检查本地链接、公开文件与提交历史；学习记录留在被忽略的本机目录 | [公开内容检查](../src/cs_study_map/validate.py)、[学习记录测试](../tests/test_study.py)、[CI](../.github/workflows/ci.yml) |

程序验证目前由逐章测试承担，统一的运行报告仍在计划中。来源失效标记、基本失败处理与禁止自动重放推理请求已有实现；后续维护会增强诊断、用量记录和回归覆盖。

## 如何复现现有成果

先按[运行说明](usage.md)安装项目。在仓库根目录使用同一 Python 环境执行：

```bash
cs-study-map build
cs-study-map validate --tracked
python -m unittest discover -s tests -v
```

这些检查使用仓库已有数据和本地测试样例，无需配置模型密钥。构建负责渲染和校验，不自动运行新生成的模型代码；测试执行的是仓库中已经审读的原创程序。CI 还检查重建后公开输出是否一致。

## 支持将用于哪些未完成工作

下一批教材是回溯与搜索剪枝、贪心算法和动态规划入门，目标新增 3 章、30 段经运行检查的程序。相应的软件维护包括统一程序验证报告、独立参考测试、生成失败诊断与实际用量记录。详细交付和验收方式见[未完成清单](roadmap.md)。
