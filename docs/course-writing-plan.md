更新于 2026-10-24。本表落实“按原来的课程分类写”：以原领域和原课程为主入口，在课程内部按先修关系组织单元。具体课程名与归属以 [courses.json](../config/courses.json) 为准，领域名称以 [taxonomy.json](../config/taxonomy.json) 为准；本表的待写单元是项目自学编排，不宣称复刻某年官方课程大纲。

当前映射覆盖 **65 个课程／资料分组：八个专业领域中的 61 个分组，加 4 个通识分组**。早期归档中的 **60 份课程指南** 是另一种口径：其中面向对象的两位教师来源共用一份合并指南，通识四组没有对应的完整归档指南。不得把来源分组数、指南数、章节数或已完成课程数混为一谈。“待分类”保留为来源入口，新增课程核对名称和归属后再加入本表。

原课程表与当前上游索引尚有目录差异：部分课程当前以自动分组索引，部分暂未匹配到资料。本表分别链接实际存在的索引或原分类记录，并标明需核对的入口；历史指南仍可阅读，不能因此声称当前原资料已经齐全。

## 阅读与续写规则

1. 先选领域和原课程，再选课程内单元。已有第 1–36 章继续使用原链接与章号；借读只引用同一正文，不复制或重复计入完成数量。
2. 每个新单元先写“所属课程、先修、学习目标、适用语言或数学模型、验收方法”。跨课程材料指定一个主要归属，其他课程提供回读链接。
3. 每章保持实质讲解、2 个原创例题、3 道练习与完整解答、自测和来源说明。计算课程保留独立可运行代码并实际验证；数学课程给完整推导和证明，程序枚举只作辅助；工程实验记录环境与真实运行证据，不用统一的代码段数量代替学习目标。
4. C++、Java、Qt、汇编、HDL 等课程按课程对象编写，并记录实际使用的工具链。现有 Python 算法讲解可以复用概念，尚未覆盖的语言、资源、平台和实验语义仍明确列为待写。
5. 阅读旧指南用于确定选题和寻找材料。动笔时再核对相应原资料及权威文档，重写原创例题与解答；指南中的知识清单不算已完成教材，来源中的学生代码不直接移植为答案。
6. 一次只展开一门课的相邻单元，或有明确先修关系的一组课程。完成讲解、例题、练习解答与相应验证后更新该单元状态；整门课程另需覆盖检查和综合验收。

新增正文时，在本表对应课程下更新覆盖与链接，并在实际章节计划中登记所属单元的范围；已完成正文继续从原链接阅读。修改课程分类时同步核对本表与课程索引，保持原课程名称可追溯。面向对象的两份教师资料共用基础讲解时只计一个正文；两份英文物理资料先比对覆盖，再复用相同理论单元。
