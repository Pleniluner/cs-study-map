| 章节 | 本章使用的表示 | 练习时优先画什么 |

## 每章做完怎样检查

1. **数组：先看边界，再看搬移。** 插入允许在有效末尾，删除必须指向已有元素；满表和非法位置应保持不变。分别运行空表、单元素、负数、零和重复值。先画旧状态，再确认搬移方向不会覆盖尚未读取的旧值。用[第 6 章练习](textbook/06-arrays.md#practice)检查最大值、筛选与逆序。
2. **链表：同时看值和链接。** 删除头结点后接回新头；删除重复值时确认只少一个结点；反转后确认原头成为尾且后继为空。空链、单结点、首尾操作都要实际运行。值顺序正确之外，还要检查没有丢失结点或形成环，见[第 7 章练习](textbook/07-linked-lists.md#practice)。
3. **栈：分开看返回值与状态。** `peek` 不减少长度，成功 `pop` 才减少；空结果 `None` 不能与合法整数 `0` 混淆。括号题分别检查错误前缀、剩余左括号和类型交错，见[第 8 章练习](textbook/08-stacks.md#practice)。
4. **队列：至少让下标绕回开头一次。** 从容量 1、2 的小队列开始，反复入队、出队、入满后拒绝、出空后再出队。失败时底层槽位、队首和数量都应保持。用[第 9 章练习](textbook/09-queues.md#practice)核对零值、回绕和批量取出。

每次只改变一个输入或操作，先手算再运行。返回结果不同，从第一处差异定位；不要只改打印，让错误状态被好看的输出遮住。个人记录可以写：“第 9 章容量 2，取空后 `head` 仍为 1；我错误地把下标 0 当队首，下次先按逻辑偏移取余。”

## 循环队列的两个视图

第 9 章的容量为 4、`head = 2`、`size = 3` 时，底层和逻辑顺序如下。下标 0 的 55 是最新进入的一项，不是下一项出队的数据。

| 物理下标 | 0 | 1 | 2 | 3 |
| --- | --- | --- | --- | --- |
| 槽位内容 | 55 | None | 33 | 44 |
| 逻辑位置 | 第 3 项 | 空槽 | 第 1 项（队首） | 第 2 项 |

逻辑顺序为 `[33, 44, 55]`，下一次出队返回 33。下一写入位置为 `(2 + 3) % 4 = 1`。只有 `size` 指定的三项属于当前队列；本书用 `size` 区分空满并使用全部容量，不额外空出一个槽位。

## 操作短不代表成本相同

以下只比较本章模型中随元素数量增长的主要工作，不含打印整个结构、构造观察列表和大整数计算的成本。`n` 是有效元素数。

| 操作 | 本章需要的主要工作 |
| --- | --- |
| 已知合法数组下标的读写 | 直接访问对应位置 |
| 顺序表头部插入、删除 | 最坏搬移与 `n` 成正比的元素 |
| 链表按值查找、仅凭头找尾 | 最坏访问整条链 |
| 已知结点后插入、已知前驱后删除 | 改固定数量的链接；定位成本另算 |
| 列表末端栈操作 | 避免整体前移；动态扩容使某次操作可能较贵 |
| 固定容量循环队列入队、出队 | 固定数量的字段和槽位更新 |

常见 CPython 列表的实现细节见各章官方文档链接；更完整的链表与循环数组分析见 [Open Data Structures 的链表章节](https://opendatastructures.org/newhtml/ods/latex/linkedlists.html)和[数组结构章节](https://opendatastructures.org/newhtml/ods/latex/arrays.html)。本书采用自己的入门接口与例题，其中固定容量队列满时拒绝新项，与动态扩容或自动丢弃旧项的容器应分别比较。
