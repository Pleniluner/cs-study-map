# 汇编语言程序设计

*依据本目录的 x86/x86-64 作业、系统调用与内存分配练习、MIPS 异常实验，以及 Bomb/Buffer/Attack Lab 整理；目标是把机器表示、调用约定、调试和底层程序设计连成一条主线。*

---

## 📋 课程定位

汇编语言是理解编译器、操作系统和处理器之间接口的工具。学习重点不是背诵指令表，而是能从位模式、寄存器、内存和控制流解释一个程序为何得到当前结果，并能在没有高级语言抽象保护时维护调用约定、栈和资源生命周期。

本目录同时含 x86-64、IA-32 和 MIPS 材料。阅读时必须先确认体系结构、位宽、ABI 和工具链，不能把不同环境的寄存器、指令编码或栈布局混用。

## 🎯 应掌握的知识

- 整数补码、移位与溢出、IEEE 754 单精度表示、字节序和位级转换。
- x86/x86-64 通用寄存器、标志位、寻址方式、条件码、跳转和循环。
- C 表达式、数组、结构体、指针、switch 和递归到汇编的映射。
- 函数调用约定：参数与返回值、callee/caller-saved 寄存器、栈帧和对齐。
- GNU assembler、链接器、ELF、符号、反汇编和系统调用接口。
- 用汇编完成文件 I/O、记录处理以及基于 brk 的动态内存分配。
- 使用 GDB 观察寄存器、栈、内存、断点和单步控制流。
- MIPS Cause、EPC、BadVAddr、异常入口、分支延迟槽和返回现场。
- 在课程提供的受控二进制中理解缓冲区越界、代码注入和 ROP 的原理及防护意义。

## ⚙️ 实践主线

### 从 C 到汇编

选择短小 C 函数，用优化前后的编译结果回答：变量位于寄存器还是栈、比较如何设置条件码、结构体如何传递、循环在哪里回边。最终应能从汇编恢复接近原始的控制流和数据布局。

### 文件 I/O 与分配器

文件作业要处理短读写、系统调用返回值、记录边界和资源释放。分配器要明确块头、空闲链表、对齐、分裂与合并不变量，并用连续分配、交错释放、零/大尺寸和耗尽场景测试碎片与错误路径。

### 反汇编与异常

Bomb Lab 适合训练静态阅读与动态验证配合；Buffer/Attack Lab 用于理解栈破坏与控制流保护；MIPS 实验则训练异常状态寄存器、精确恢复和分支延迟槽。三者都要求逐条记录“当前指令—寄存器/内存变化—下一控制点”。

## 🔍 学习与调试方法

1. 每次先确认架构、位宽、ABI、汇编语法和目标文件格式。
2. 对函数画栈帧，标出返回地址、保存寄存器、局部变量和参数。
3. 静态反汇编先提出假设，再用 GDB 单步、watchpoint 和内存检查验证。
4. 任何位运算同时写十六进制和二进制，明确有符号/无符号解释。
5. 系统调用后立即检查返回值；崩溃时先检查栈对齐、保存约定和边界。
6. 将错题按数据表示、ABI、控制流、内存、异常分类，而不是按试卷年份堆放。

## ⚠️ 归档与安全说明

- 目录中既有 32 位也有 64 位材料。归档经验特别提醒不要忽略 IA-32 题目；复习时应分别维护寄存器、ABI 和栈布局表。
- 现有经验认为，围绕计算机系统视角理解汇编比孤立背指令更有效；本目录的作业、反汇编与历年题应相互印证。
- 历年题和在线课程题型可能与归档年份相关，不能视为当前考试范围或原题保证。
- Bomb、Buffer 和 Attack Lab 只允许用于课程提供的本地目标文件及隔离实验环境。不得将其中技术用于未获授权的程序、设备或网络。
- 老实验可能依赖 32 位库、旧版编译器或关闭现代保护的环境。保留原始资料，在单独副本中搭建兼容环境。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 在补码、IEEE 754、字节序和位宽之间完成准确转换并说明溢出。
2. 阅读一段 x86/x86-64 汇编，恢复函数、循环、分支和数据结构。
3. 按 ABI 正确编写函数和系统调用代码，维护栈、寄存器与错误路径。
4. 完成一个文件记录程序和一个最小内存分配器，并用边界用例验证。
5. 熟练使用 objdump/GDB 定位控制流、参数、内存和崩溃原因。
6. 在受控目标上解释栈覆盖与 ROP 的机制，同时说明 NX、栈保护和地址随机化的防护作用。
7. 正确解释一次 MIPS 地址异常的 Cause、EPC、BadVAddr 与恢复流程。
