# 计算机组成原理

*依据本目录的书面作业、历年题和“自己动手写 CPU”32 位 OpenMIPS/DE2 工程整理；目标是从数据表示、存储与 I/O 一直贯通到可仿真、可上板、可运行软件的处理器。*

---

## 📋 课程定位

计算机组成原理回答“指令怎样由数字电路执行”。理论部分覆盖数值表示、运算器、存储层次和 I/O；实践部分通过 Verilog 逐步构造五级流水 MIPS CPU，再扩展异常、中断、总线、外设、BootLoader 和嵌入式操作系统。

学习时不要把书面题和造机分开：补码决定 ALU 行为，Cache 和存储器决定取指/访存，流水相关决定暂停与转发，中断题最终对应 CP0 和异常入口。

## 🎯 应掌握的知识

- **数据与运算**：补码、无符号数、IEEE 754、Hamming 校验、定点乘除、Booth 算法和溢出。
- **数字逻辑**：组合/时序逻辑、寄存器、触发器、有限状态机、时钟和复位。
- **指令系统**：MIPS 指令格式、译码、寄存器堆、立即数扩展、分支和访存语义。
- **数据通路与控制**：PC、IF/ID/EX/MEM/WB、控制信号和模块接口。
- **流水线**：数据相关、结构相关、控制相关、转发、暂停、清空、分支延迟槽和多周期除法。
- **存储系统**：Cache 地址字段、局部性、命中率、AMAT、虚拟存储/TLB 和内存接口。
- **I/O 与异常**：中断优先级与屏蔽、轮询/中断/DMA、CP0、EPC、Cause、精确异常和返回。
- **SoC 与 FPGA**：总线、ROM/RAM、Flash、SDRAM、UART、GPIO、时序约束、综合和板级调试。
- **验证方法**：testbench、波形、断言式检查、汇编测试、逐级回归和软硬件协同。

## 🔍 造机与验证方法

1. 为每一阶段定义最小指令集和接口，不一次加入多类功能。
2. 先手算一段短汇编的逐周期状态，再写 testbench。
3. 每新增一条指令，同时补译码、执行、写回/访存路径和正反例测试。
4. 用波形检查 PC、流水寄存器、写使能、目标寄存器和暂停/清空信号。
5. 保留前面章节的回归测试，防止新指令破坏旧功能。
6. 仿真完全通过后才综合和上板；板上问题再区分逻辑、时序、引脚、电源和外设协议。
7. 每次检查前保留可运行节点、变更记录和已知问题，避免在截止日前合并大量未验证代码。

理论复习要与工程交叉：例如做 Cache 题后画出 CPU 的访存接口，做中断题后跟踪 CP0 与流水线清空，做分支预测题时回到状态机与触发器。

## ⚠️ 归档经验与环境说明

- 现有归档以 32 位造机为主，不能把早期 16 位或其他课程的接口假设直接带入。
- 原 README 的经验表明，造机检查分散在学期中，临近检查才集中拼接代码会导致“仿真通过但上板失败”。应按章节建立周级里程碑。
- FPGA 全量编译可能耗时较长；开发机性能、增量编译和小模块仿真会明显影响迭代效率。每次修改前先判断是否真的需要重新综合。
- 工程包含大量 Quartus 中间产物、网表和历史二进制。它们不保证与当前工具兼容，也不应作为源码正确的证据。
- 归档考试经验提示 Cache、分支预测/数字逻辑和 RAID 等边界主题都可能出现，但这只反映某一年试题；复习范围必须以当前教学要求为准。
- 在单独副本中搭建旧版 Quartus/工具链，保留本目录原始工程。接 FPGA 前先核对板卡手册、电压、引脚和供电。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 完成补码、浮点、校验、乘除和 Cache/中断类书面推导，并写清假设与单位。
2. 画出五级流水 CPU 的模块、控制信号和一条指令的逐级路径。
3. 用 Verilog 增量实现一组 MIPS 指令，正确处理转发、暂停、分支和多周期单元。
4. 使用 testbench、波形与汇编回归定位至少一种数据相关和一种控制相关错误。
5. 解释 Load/Store、LL/SC、CP0、异常和中断如何影响流水线状态。
6. 将 CPU 与 ROM/RAM、UART/GPIO 等外设集成，并区分仿真、综合和上板问题。
7. 形成从汇编程序、BootLoader 到操作系统运行的软硬件整体认识，而不只停留在复制现成 RTL。
