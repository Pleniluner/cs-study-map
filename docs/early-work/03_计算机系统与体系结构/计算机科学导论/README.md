# 计算机科学导论

*依据本目录的两份复习提纲和两份历年题整理；目标是建立计算机科学全景地图，理解各分支之间的接口，而不是在导论阶段追求每个主题的实现深度。*

---

## 📋 课程定位

这门课从数据表示和机器执行出发，向上连接操作系统、网络、算法、程序设计语言、数据结构、数据库、人工智能与可计算性。学习成果应是一张稳定的知识地图：遇到新问题时，能判断它属于哪一层、使用什么抽象、受什么限制。

## 🎯 应掌握的知识

| 模块 | 应掌握的核心概念 |
|---|---|
| 数据存储 | 门电路与触发器、磁盘/光盘、二进制、补码、浮点数、压缩 |
| 数据操纵 | 冯·诺依曼结构、机器语言、取指—译码—执行 |
| 操作系统 | 历史、内核结构、进程、资源分配和死锁 |
| 网络 | 分层、IP 地址、分组交换与路由 |
| 算法 | 算法定义、伪代码、迭代/递归、复杂度、P/NP/NP 完全 |
| 程序设计语言 | 语言世代、范式、过程、值/引用传递、词法与语法分析 |
| 数据抽象 | 数组、链表、栈、队列和树 |
| 文件与数据库 | 文件描述、顺序/直接/索引/散列组织、关系操作 |
| 人工智能 | 图搜索、八数码问题和图灵测试 |
| 可计算性 | 图灵机、停机问题和不可解问题 |

导论层面的“掌握”意味着会解释、比较和完成小型推演；后续课程再分别深入实现。

每完成一个模块，都用一句话回答它“向下依赖什么、向上提供什么”。例如，操作系统向下依赖硬件中断和存储，向上提供进程、文件和网络抽象。

## ⚙️ 必会推演

- 在同一位模式下分别解释无符号数、补码整数和浮点数。
- 逐步执行一段简化机器指令，记录 PC、寄存器和内存变化。
- 画进程资源等待图，判断是否满足死锁条件。
- 描述一个分组从发送端经路由器到接收端所经过的分层。
- 跟踪二分查找或递归算法，给出时间复杂度的数量级。
- 比较值传递与引用传递对调用者变量的影响。
- 用栈/队列模拟操作，用树和散列表解释查找过程。
- 演示一次关系连接、一次八数码搜索和一个简化图灵机步骤。
- 能说明“暂时不会做”和“原则上不可计算”不是同一概念。

## 🔍 复习方法

1. 第一遍按短提纲建立十个模块的一页总览。
2. 第二遍阅读完整提纲，为每个概念写定义、最小例子和一个易混点。
3. 回看课程作业；归档经验指出，考题与作业训练联系紧密，因此作业应优先于刷旧题。
4. 将历年题拆回知识模块，先不限时完成，再做一轮限时综合卷。
5. 对错题解释错误原因：表示混淆、步骤遗漏、概念边界还是不会应用。
6. 考前只复盘总览、错题和典型推演，保留休息时间。

## ⚠️ 归档使用说明

- 本目录仅有复习材料和旧试题，没有课程讲义、作业原题或实验工程，因此 README 提供的是基于现存资料的学习范围。
- 旧试题的年份、难度和考核范围不能代表当前课程；原 README 中“主要参考某一届试题”的经验应理解为归档建议，而非预测。
- 扫描页若无法辨认，应回到提纲和教材确认，不根据模糊 OCR 猜题意。
- 熟悉竞赛算法并不等于掌握操作系统、网络、数据库或可计算性概念，复习时仍要覆盖全图。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 用一张图说明数据、机器、系统、程序、数据组织、AI 和计算理论之间的层次。
2. 对每个模块准确解释核心术语，并给出至少一个例子。
3. 完成位表示、机器执行、算法复杂度、数据结构、关系操作和搜索的小型推演。
4. 区分容易混淆的概念，如程序/进程、值/引用、文件组织/数据结构、P/NP/NP 完全。
5. 在不依赖答案的情况下完成历年题，并能把错误定位到对应模块。
6. 说明计算机能解决哪些类型的问题，以及资源限制与不可计算性的区别。
