# 信息科学技术概论

*依据本目录现存的四篇作业整理；资料呈现的是科技主题调研与论证写作训练，而非完整课程讲义或正式作业要求。*

---

## 📋 课程定位

现有作业从人工智能史、人类与机器智能差异、社会背景对科技进步的影响，延伸到无人驾驶的技术与社会利弊。由此可见，本项目适合训练两类能力：

- 建立信息科技的历史、技术和社会影响全景。
- 把宽泛话题收束为可论证的问题，并用可靠资料写成结构完整的论文。

README 只根据现存提交件归纳，不把其中观点当作课程标准答案。

## 🎯 应掌握的知识与能力

- 按时间、技术范式或问题演化梳理一个信息科技主题。
- 区分事实、解释、价值判断、预测和个人意见。
- 把大主题缩小为明确研究问题，提出可辩护的中心论点。
- 从技术机制、历史条件、经济成本、伦理风险和治理角度进行多维分析。
- 搜集并评价资料的作者、时间、证据、出处和适用范围。
- 组织摘要、关键词、引言、正文、结论和参考文献。
- 公平呈现支持与反对证据，避免把“利弊罗列”误当作论证。
- 规范转述和引用，维护参考文献与正文引证的一致性。
- 通过提纲、初稿、事实核查和语言修订迭代完成长文。

## ⚙️ 一篇作业的标准结构

### 开题卡

写作前用一页回答：研究对象、时间/地域范围、核心问题、预期论点、三个分论点、可能反例和计划使用的资料类型。

### 正文结构

1. **引言**：说明问题、范围、重要性和中心论点。
2. **背景/机制**：只解释后文论证真正需要的技术与历史。
3. **分论点**：每段采用“主张—证据—解释—限制”的结构。
4. **反方与边界**：呈现最强反对意见，说明何时结论不成立。
5. **结论**：回答研究问题，概括证据，不引入未经论证的新观点。
6. **参考文献**：确保每条都在正文使用，正文引用也都能在文末找到。

摘要应在正文完成后写，概括问题、方法/材料、主要结论和限制；它不是引言的重复。

## 🔍 资料与论证检查

| 检查项 | 自问 |
|---|---|
| 来源 | 作者和机构是谁？是原始材料、研究还是二手转述？ |
| 时间 | 技术、政策或统计是否已过时？ |
| 证据 | 这是数据、案例、专家判断还是推测？ |
| 因果 | 只是同时发生，还是有机制和对照支持因果？ |
| 代表性 | 单个案例能否推广，是否存在反例？ |
| 公平性 | 是否准确呈现相反观点，而非设置稻草人？ |
| 引用 | 转述是否忠实，页码/出处是否可追溯？ |
| 结论 | 结论强度是否与证据强度匹配？ |

涉及人工智能和无人驾驶等快速变化主题时，应特别记录资料发布日期和研究适用场景。

## ⚠️ 归档经验与限制

- 原 README 建议尽早完成一篇约 3000 字和三篇约 1000 字的作业，以免后期任务堆积。这是某一学期的个人时间管理经验，不代表当前作业数量、字数或截止日期。
- 当前目录没有课程大纲、教师反馈和评分量表，无法据此恢复官方学习范围。
- 四篇文档可能包含较旧或质量不一的网络来源。引用其中事实前应重新查证，不能因其已出现在提交件中就视为可靠。
- 可以借鉴主题分解和文章结构，但不得复制原文作为自己的作业。
- 建议建立写作日程：选题、资料卡、提纲、初稿、核查和定稿分别留出时间，不把长文压到截止日前。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 将一个宽泛科技主题转化为范围明确、可以回答的研究问题。
2. 建立可追溯的资料卡，区分原始证据、二手分析和个人判断。
3. 写出有中心论点、分论点、反方观点和适用边界的文章。
4. 对人工智能、无人驾驶等技术同时说明机制、历史背景与社会影响。
5. 识别案例推广、相关冒充因果、过时资料和结论过强等常见问题。
6. 完成摘要、关键词、正文引证和参考文献的一致性检查。
7. 通过至少两轮修订，使文章在事实、逻辑、结构和语言上均可复核。
