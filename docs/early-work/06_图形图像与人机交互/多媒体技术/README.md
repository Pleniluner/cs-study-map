# 多媒体技术

*依据本目录中的图像编码、内容检索、音频变换、信息熵、算术编码、QAM 和分色立体实验整理；目标是贯通媒体表示、压缩、传输、检索与质量评价。*

---

## 📋 课程定位

多媒体系统同时处理图像、视频、音频和文本。现有资料不是一套连续讲义，而是多组实验提交：既包含 DCT 与量化等压缩基础，也包含基于颜色直方图的图像检索、语音分析/变换、熵与算术编码、彩色视频信号调制以及红蓝立体图制作。

学习时应围绕统一问题组织这些材料：媒体如何采样和表示，怎样减少冗余，处理或传输后损失了什么，以及如何用主观观察和客观指标共同验证。

## 🎯 应掌握的知识

- 图像采样、量化、灰度/RGB/YUV/YIQ 等表示及颜色分量转换。
- 一维/二维 DCT、8×8 分块、能量集中、系数量化、逆变换和压缩失真。
- MSE、PSNR、运行时间和压缩参数曲线的计算与局限。
- 概率分布、自信息、信息熵、冗余和算术编码/解码区间更新。
- 颜色直方图、bin 数、L2、Histogram Intersection、Bhattacharyya、Canberra、Jeffreys 等相似度。
- 内容检索中的查询集、Top-K 返回、类别准确率和颜色特征的语义局限。
- 音频波形、频谱、基频、共振峰、时长、音色与语音变换的基本思路。
- FFT、滤波、正交载波、QAM 调制/解调及亮度/色度复用。
- 双目视差、颜色通道合成和分色立体图的基本构造。
- MATLAB、Python、Java/C++ 实验的输入输出、参数控制和可复现报告方法。

## ⚙️ 实验主线

### 图像编码与质量

1. 把输入转换为明确的数据类型和范围，保留无损重构基线。
2. 分别实现全图 DCT、8×8 分块 DCT、系数截断和量化/逆量化。
3. 扫描保留比例或量化缩放参数，记录 PSNR、时间和结果图。
4. 检查归一化是否改变比较尺度，避免用显示函数掩盖数值错误。
5. 用低频/高频、人眼敏感性和块效应解释曲线。

### 内容检索

为每张图计算归一化颜色直方图，以相同查询集比较 bin16/bin128 和不同距离。除整体准确率外，还应检查各类别、失败查询和返回列表，说明颜色分布为何不能表达空间结构、纹理与对象语义。

### 音频与传输

音频实验应保存原始和变换后的波形、频谱、基频、共振峰与时长；QAM 实验则逐步验证颜色空间转换、频谱搬移、滤波和重建。每一步都要设置可单独检查的中间输出。

## 🔍 分析与验证方法

| 任务 | 必须控制的变量 | 至少保留的证据 |
|---|---|---|
| DCT/量化 | 图像、分块、系数/量化矩阵、数据范围 | 重构图、PSNR、耗时、参数曲线 |
| 熵/编码 | 符号集合、计数规则、概率和、精度 | 频率表、熵、编码区间、解码回放 |
| 图像检索 | 数据集、query、bin、距离、Top-K | 排名结果、总体/分组指标、失败案例 |
| 音频变换 | 采样率、基频、共振峰、时长参数 | 波形、频谱、试听文件、伪影说明 |
| QAM | 载波、FFT 窗口、滤波器和输入帧 | 调制前后频谱、分量和重构画面 |

结果报告应同时回答正确性、质量、速度和局限，不能只展示“效果最好”的样例。

## ⚠️ 归档与环境说明

- 资料来自多位学生和不同年份，lab1/lab2 与独立提交目录存在平行版本及重复数据集；保留原结构，选择一个主版本复现即可。

- 信息熵样本含整部长篇文本，图像检索目录含大批数据图片。仅用于本地学习，重新分发前应确认授权和数据来源。
- 报告中的数值与结论只对应当时实现和样本；尤其要独立检查概率归一化、PSNR 数据范围和计时方法。
- 压缩包无需改动或展开到本归档目录；可在单独实验目录读取。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 在常见颜色空间之间转换，并解释亮度与色度分离的意义。
2. 独立实现分块 DCT、量化与逆变换，画出参数—质量—时间关系。
3. 从符号频率计算熵，并手工/程序完成一个算术编码与解码闭环。
4. 建立颜色直方图检索基线，比较至少三种距离并分析失败案例。
5. 对语音的波形、频谱、基频和共振峰进行基础分析与可控变换。
6. 说明并验证正交调制、频谱搬移、滤波解调和图像分量重建。
7. 用固定输入、参数记录、客观指标和可视/听结果写出可复现实验报告。
