# 计算机图形学基础

*当前目录保留一份真实感图像渲染报告和一个外部工程索引；以下 README 以报告中的渲染器设计为主线，整理学生应掌握的数学、算法、工程与验证能力。*

---

## 📋 课程定位

计算机图形学把几何、光学、数值方法和程序设计转化为图像。现有报告覆盖从向量/矩阵、射线求交到 Ray Tracing、Path Tracing、Photon Mapping、PPM/SPPM，并进一步实现 Bézier 曲面、KD-Tree、纹理、法线贴图、景深和体积光。

项目目标不只是生成“好看的图”，而是构造一个可扩展、可验证的渲染系统：每个像素从哪里来，采样是否正确，几何求交是否稳健，噪声为何收敛，优化是否改变了结果，都应能解释。

## 🎯 应掌握的知识

- 二维/三维向量、点积/叉积、齐次坐标、矩阵、局部/世界/相机坐标变换。
- 相机模型、投影、主光线、抗锯齿采样和景深。
- 射线与球、平面、三角形、包围盒、网格和旋转 Bézier 曲面的求交。
- 法向、重心坐标、纹理坐标、OBJ 网格和层次化场景表示。
- AABB、KD-Tree、近侧优先遍历和包围体剪枝。
- 漫反射、镜面反射、折射、Fresnel、吸收、直接光照与可见性。
- Monte Carlo 积分、重要性采样、分层采样、方差与收敛。
- Ray Tracing、Path Tracing、Photon Mapping、PPM 和 SPPM 的数据流与差异。
- 环境/纹理/法线映射、景深、体积光等效果的物理含义和采样代价。
- 渲染器架构、随机数可复现、性能剖析、图像对比和技术报告写作。

## ⚙️ 渲染项目主线

### 最小正确实现

先只实现相机、球/平面、漫反射材质和一个小场景。使用固定随机种子、低分辨率和少量样本快速迭代；通过解析几何和对称场景验证射线方向、最近交点、法向朝向和阴影。

### 可扩展场景

再引入 Object/Material/Light 接口、变换矩阵、三角网格和 OBJ。求交结果应统一携带距离、位置、几何/着色法向、纹理坐标和材质，避免每种物体把渲染逻辑复制一遍。

### 复杂光传输

在基线图上依次加入折射/Fresnel、重要性采样、光子图、渐进半径更新和超采样。每次只改变一个算法因素，并用同一相机、场景、样本预算比较噪声和时间。

### 建模与效果

Bézier 需要参数求值、导数/法向、包围盒和稳健的非线性求交；纹理、法线贴图、景深和体积光则应分别验证坐标系、过滤、采样分布及能量一致性。

## 🔍 验证与评价方法

| 层次 | 验证问题 | 建议证据 |
|---|---|---|
| 数学 | 变换可逆吗？法向和坐标系方向正确吗？ | 单元测试、已知向量结果 |
| 几何 | 是否返回最近正交点？切线、平行和盒边界稳定吗？ | 人工可解射线、法线可视化 |
| 光照 | 遮挡、反射、折射和能量权重正确吗？ | 单材质/单光源对照场景 |
| 随机算法 | 增加样本是否趋于稳定？是否存在系统偏差？ | 固定种子、样本数—误差曲线 |
| 加速 | 输出不变吗？访问和时间真正下降吗？ | 开关 KD-Tree 的逐像素对比 |
| 工程 | 新特性是否破坏旧场景？ | 小型回归场景集 |

作品展示应同时给出参数、分辨率、样本数、运行时间、硬件和已知缺陷，不能只放最终图片。

## ⚠️ 归档经验与使用边界

- 当前目录只有报告，没有完整 C++ 源码、场景和结果图；不能把报告中的 7586 行工程描述当作本地可运行项目。
- 旧 README 提到 SPPM 实现仍有 bug。复现时必须用基线和收敛测试独立验证，不能根据最终效果图判断正确。
- 历史经验强调 Bézier 求交等独立算法贡献比堆叠效果更有价值。学习时应解释问题、推导方法并给出失败边界。
- 不应直接复制他人的大型面向对象实现；先写最小版本，再依据新增需求重构，接口才会服务于自己的设计。
- 4K、多采样渲染可能消耗大量 CPU、内存和时间。只能使用自己拥有或明确获准的计算资源，先用小图完成正确性验证。
- 外部索引和工具链可能已变化；如需获取代码，应另存到实验目录，不修改本归档。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 推导并实现相机射线、坐标变换及常见几何体求交。
2. 构造可扩展的场景、物体、材质、光源和交点数据结构。
3. 实现最小 Path Tracer，并用固定场景说明采样、噪声和收敛。
4. 加入纹理、法线映射、折射/Fresnel 和至少一种相机效果。
5. 实现并验证 AABB/KD-Tree，证明加速前后图像一致。
6. 解释 Bézier 曲面求值、法向、包围与求交中的数值问题。
7. 比较 PT、PM、PPM/SPPM 的状态、偏差/方差、内存和适用场景。
8. 提交包含算法推导、测试场景、参数、性能、失败案例和授权算力说明的报告。
