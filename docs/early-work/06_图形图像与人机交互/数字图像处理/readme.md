# 数字图像处理

*依据本目录现存的 2017 大作业报告和 2018 外部工程索引整理；主线从像素/直方图处理、重采样与质量评价，延伸到人脸检测、局部特征和图像差异识别。*

---

## 📋 课程定位

数字图像处理研究如何表示、增强、变换、分析和理解离散图像。现有本地报告覆盖三部分：点处理，最近邻/双线性/双三次/Lanczos 重采样，以及以 Haar/AdaBoost、FAST 和简化梯度描述子进行照片人物差异检测。

旧 README 还提到 Poisson Image Editing 和后半学期的机器学习内容，但相应题目、代码和报告不在本地目录。因此本 README 将它们保留为历史课程线索，不把它们写成本地可直接完成的实验。

## 🎯 应掌握的知识

- 像素坐标、通道、数据类型、动态范围、灰度与常见颜色表示。
- 亮度、对比度、Gamma、饱和度等点运算及溢出/截断处理。
- 直方图、累计分布、直方图均衡化和匹配。
- 采样、混叠、预滤波，以及最近邻、双线性、双三次和 Lanczos 插值。
- MSE、PSNR、运行时间和视觉质量的关系与局限。
- 卷积、梯度、角点/特征点和局部方向直方图的基本思想。
- Haar 特征、积分图、AdaBoost 和级联检测器的训练/推理结构。
- 特征匹配、阈值、重叠框去重、误检/漏检和尺度/旋转不变性。
- 训练/验证/测试划分、数据偏差、基线、消融和可复现评价。
- Poisson 图像编辑中的梯度域目标、边界条件和稀疏线性方程组，作为后续扩展。

## ⚙️ 现存报告的三条实验线

### 点处理

实现亮度、对比度、Gamma、直方图均衡/匹配和饱和度调整。测试全黑/全白、窄动态范围、单色和普通照片，确认各通道与输出范围正确，并同时展示直方图和图像。

### 图像重采样

用同一原图分别降采样再恢复到原尺寸，比较最近邻、双线性、双三次和 Lanczos。应区分插值核、边界处理和抗混叠预滤波，记录不同尺寸下的 PSNR、时间及典型伪影。

### 照片差异识别

报告的实现先检测人脸，再通过 FAST 点和局部梯度方向描述进行跨图匹配。复现时应拆分为检测、特征、匹配和人物级决策四步；每一步分别评估，避免用手工偏移或特定肤色阈值掩盖上游错误。

## 🔍 实验与评价方法

| 阶段 | 必做基线 | 关键指标 | 失败分析 |
|---|---|---|---|
| 点处理 | 恒等变换 | 数值范围、直方图 | 溢出、色偏、空 bin |
| 重采样 | 最近邻 | PSNR、时间、视觉伪影 | 混叠、模糊、振铃、边界 |
| 检测 | 固定窗口或现成基线 | Precision、Recall、耗时 | 尺度、姿态、光照、遮挡 |
| 特征匹配 | 最近邻描述子 | 正确匹配率、误配 | 重复纹理、视角、尺度 |
| 端到端差异识别 | 人工标注 | 人物级 TP/FP/FN | 上游错误传播 |

至少固定随机种子和参数，分离训练与测试图片，记录环境、输入、命令和原始结果。PSNR 不能单独代表感知质量，训练集正确率也不能代表泛化性能。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 正确处理图像通道、数据类型和动态范围，实现主要点运算。
2. 从累计分布推导并实现直方图均衡与匹配。
3. 实现并比较四种重采样方法，解释混叠、模糊和振铃。
4. 使用 PSNR、运行时间和视觉案例共同评价重建质量。
5. 说明 Haar/AdaBoost 检测器和 FAST/梯度描述子的工作链。
6. 将检测、特征、匹配和人物决策分阶段评价，报告 TP/FP/FN。
7. 识别数据泄漏、训练偏差、手工规则和指标选择造成的误导。
8. 在获得正式题目后，独立完成一个梯度域图像编辑或同等级综合项目并写出可复现报告。
