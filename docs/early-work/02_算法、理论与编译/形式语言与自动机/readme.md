## 📚 形式语言基础与能力层次

### 基本对象与运算

- 字母表是有限符号集合；串是符号的有限序列；`ε` 是长度为零的空串，`∅` 是不含任何串的空语言，二者不可混淆。
- 掌握串的长度、连接、幂、反向、前缀/后缀/子串，以及语言的并、交、差、补、连接、Kleene 闭包和正闭包。
- 能用结构归纳定义串函数，并对串长度、反向和同态保持性作归纳证明。
- 区分语法对象与语义集合：正规表达式、文法和自动机是表示；它们所描述或接受的语言才是语义。

### 文法、推导与分析树

- 掌握文法 `G=(V,T,P,S)`、直接推导、多步推导、句型、句子、最左/最右推导。
- 能由推导构造分析树，由分析树读出果实；理解一棵分析树可对应不同推导顺序。
- 判断文法二义性时，要为同一个串给出两棵不同分析树或两种本质不同的最左/最右推导。
- 区分“文法二义”与“语言固有二义”；优先级、结合性和最近 `else` 原则可消除某些文法二义性。
- 证明 `L(G)=L` 时通常需要双包含：从推导证明生成的串满足性质，再从目标串结构证明可由文法生成。

### Chomsky 层次与对应模型

| 文法/语言层次 | 产生式限制概要 | 对应模型 | 核心认识 |
| --- | --- | --- | --- |
| 3 型：正规 | 右线性或左线性规则 | 有限自动机 | 只有有限状态记忆 |
| 2 型：上下文无关 | 左部为单一非终结符 | 下推自动机 | 可使用一个无界栈 |
| 1 型：上下文有关 | 通常不缩短串长 | 线性有界自动机 | 工作空间受输入线性约束 |
| 0 型：无限制 | 左部含非终结符 | 图灵机 | 对应递归可枚举能力 |

还要区分递归语言与递归可枚举语言：前者存在对所有输入都停机的判定器；后者只保证属于语言的输入最终被接受，不属于时可能永不停机。

## ⚙️ 正规语言与有限自动机

### 正规表达式与有限状态模型

- 熟练使用 `∅`、`ε`、单字符、并、连接和闭包归纳构造正规表达式。
- 掌握 DFA、NFA、ε-NFA 的五元组定义、转移函数与扩充转移，明确确定性要求。
- 设计自动机时先确定“状态需要记住的最少历史”：奇偶性、有限后缀、已见子串、计数模数或违规状态。
- DFA 的每个状态对字母表中的每个符号必须有且仅有一条出边；必要时显式加入死状态。

### 等价转换与最小化

1. 用 Thompson 构造把 RE 递归转换为 ε-NFA。
2. 计算 `ε-closure`，用子集构造把 ε-NFA/NFA 确定化为 DFA。
3. 删除不可达状态，用填表法或等价类细分最小化 DFA。
4. 用状态消去法或路径迭代法把 DFA 转回 RE。

转换时不仅要画结果，还要维护状态集合的含义，并用代表串验证新旧模型接受同一语言。DFA 最小化要区分“不可达”与“可达但等价”的状态。

### 封闭性、判定问题与泵引理

- 正规语言对并、交、补、差、连接、闭包、反向、同态和逆同态等运算具有相应封闭性；证明时应给出自动机或表达式构造。
- 能判定 DFA/RE 所表示语言的成员关系、空性、有限性和等价性；等价问题可转化为对称差语言是否为空。
- 正规语言泵引理是正规性的必要条件，不是充分条件。它通常用于反证“某语言不是正规语言”。
- 使用泵引理时必须保持量词顺序：任取泵长度，自己选择足够长的语言内串；对任意合法分解，再选择破坏语言性质的泵次数。
- 能优先使用闭包性质和已知非正规语言做逆像/交集证明时，不必强行泵一个复杂语言。

## 🔍 上下文无关语言与下推自动机

### CFG 设计、化简与规范形

- 设计 CFG 时根据串结构选择递归方向、配对关系和分段方式，并逐一检查 `ε`、零次和最小次数等极端情况。
- 掌握生成符号、可达符号和有用符号；按正确顺序消除 ε-产生式、Unit 产生式和无用符号。
- 能把适当 CFG 转为 Chomsky Normal Form，理解每一步如何保持目标语言（对 `ε` 的处理需单独声明）。
- 掌握 CYK 动态规划：表项记录能够生成某个子串区间的非终结符集合，按区间长度和切分点填表。
- 区分可判定的 CFG 成员/空性问题与一般不可判定的二义性、等价性等问题。

### PDA、DPDA 与 CFG 的关系

- 掌握 PDA 的状态、输入、栈字母表、转移和瞬时格局；能逐步写出输入位置、状态和栈内容。
- 区分终态接受 `L(P)` 与空栈接受 `N(P)`；对一般 PDA 两种方式可以互相转换。
- 能把 CFG 构造为空栈接受 PDA，也理解从 PDA 到 CFG 时变量 `[pXq]` 的含义。
- 设计 PDA 时明确栈保存什么：未匹配计数、待匹配符号、嵌套结构或阶段边界。
- DPDA 的转移必须保持确定性；终态接受和空栈接受的 DPDA 能力并不等价，不能照搬一般 PDA 的结论。
- 能通过 PDA 与 DFA 的积构造证明 CFL 与正规语言求交仍是 CFL。

### CFL 性质与非上下文无关证明

- 掌握 CFL 对并、连接、闭包、反向、同态、逆同态以及与正规语言求交等运算的性质。
- 知道 CFL 一般不对交、补和差封闭，并能构造反例或用封闭性关系推导。
- 使用 CFL 泵引理时处理 `z=uvwxy`、`|vx|>0`、`|vwx|≤n`，覆盖所有可能分解位置。
- 对多个独立相等计数、复制语言 `ww` 等问题，要判断一个栈是否足以保存所需关系。

## 📊 图灵机、可判定性与复杂性

### 图灵机与语言类别

- 掌握基本 TM 的状态、输入字母表、带字母表、空白符、转移、初态与接受状态，以及格局之间的推导。
- 能设计 TM 完成扫描、标记、回退、复制、比较和二进制运算，并证明对所有要求输入终止。
- 理解多带、多道、双向/半无穷带、非确定 TM、栈机等常见变体如何被标准 TM 模拟；区分“计算更方便”与“可计算能力更强”。
- 能从状态转移图描述机器语言，也能对给定输入逐步模拟带内容和读写头位置。

### 可判定与不可判定

- 区分识别器与判定器、递归可枚举与递归语言；理解递归语言对补封闭，而 RE 语言一般不对补封闭。
- 理解图灵机编码、通用语言、对角语言和停机问题在不可判定性证明中的作用。
- 掌握映射归约的方向：若已知难问题可归约到目标问题，则目标问题至少同样难。
- 能正确使用 Rice 定理判断“由 TM 所识别语言的非平凡语义性质”，不能把纯语法或机器运行步数性质错误套入。
- 了解 Post Correspondence Problem 等典型不可判定问题，并能识别题目要求的是构造实例、归约还是引用结论。

### P、NP 与归约

- `P`：存在确定性多项式时间算法的问题。
- `NP`：候选证书可在确定性多项式时间内验证，等价地可由非确定 TM 在多项式时间内求解。
- `NP-hard`：所有 NP 问题均可多项式时间归约到它，本身不要求属于 NP。
- `NP-complete`：既属于 NP 又是 NP-hard。
- 证明某问题 NP-complete 时，先证明属于 NP，再从已知 NP-complete 问题归约到它；归约方向写反会失去证明力。
- 不把“非确定 TM 接受的任意语言”直接称为 NP；必须有多项式时间界。

## ✍️ 证明与考试方法

### 五种常用证明模板

1. **结构归纳**：证明关于串、RE、推导树或递归定义对象的性质。
2. **双包含**：证明某文法/自动机语言恰好等于目标集合。
3. **构造证明**：直接给出新自动机、文法或算法来证明封闭性与可判定性。
4. **反证与泵引理**：严格遵守量词顺序，覆盖任意合法分解。
5. **归约证明**：从已知困难问题构造目标实例，并证明是/否答案保持对应。

### 作答流程

- 先写模型的完整类型和接受方式，例如明确是 DFA、ε-NFA、空栈 PDA 还是停机 TM。
- 画自动机前先给每个状态写语义；完成后检查每个字符的转移、死状态和边界串。
- 写 CFG 后用最短串、`ε`、临界计数和不应生成的串反向测试。
- 做转换题时保留中间表：`ε-closure`、DFA 状态集合、可区别状态对、CYK 区间集合。
- 判断题先确定量词和前提；一个反例足以推翻全称命题，但若主张恒真则需要一般证明。
- 先独立完成[2009 期中题](exam/期中/2009期中.pdf)，再用[2013 期末题](exam/期末/2013.pdf)检查全阶段能力。
