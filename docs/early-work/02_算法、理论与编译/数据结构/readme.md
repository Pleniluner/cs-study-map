## 📋 课程定位与资料地图

数据结构研究三件彼此不能分开的事：如何表示数据、如何定义并实现操作、如何证明这些操作正确且足够高效。课程中的难点通常不在记住某段代码，而在理解抽象数据类型的接口、内部表示的不变量，以及不同输入下的最坏、平均、期望和分摊代价。

## 📚 核心知识体系

### 渐进分析与算法证明

- 正确定义并使用 `O`、`Ω`、`Θ`，理解上界、下界和紧界的差异。
- 分析顺序、嵌套、条件、对数增长、移位和递归程序；会用递归树、代换或层数求和。
- 区分最坏、最好、平均、期望和分摊分析；随机算法的期望不能用一次运行结果代替。
- 理解基于比较的排序/选择可以用决策树建立下界，特定输入不必都达到统一下界。
- 不只写最终复杂度，还要明确基本操作、输入规模、求和式和主导项。

### 向量、列表、栈与队列

- 理解秩与位置、连续存储与链式存储，以及查找、插入、删除、扩容和遍历的代价来源。
- 掌握无序去重、有序唯一化、二分/Fibonacci 查找、插入排序和循环移位等典型算法。
- 能在 `O(n)` 时间、`O(1)` 附加空间内完成双指针划分与三次反转式循环移位。
- 掌握栈的 LIFO 约束、合法栈混洗及其与 Catalan 结构的联系；能处理括号、进制转换和表达式求值。
- 掌握中缀、后缀表达式和 RPN 的转换与求值，正确处理优先级、结合性、括号和一元运算。
- 理解队列、双端队列和层次遍历中的先进先出不变量。

### 字符串匹配

- 能实现蛮力匹配，并精确指出回退造成重复比较的位置。
- 掌握 KMP 的前缀/后缀思想，能手工构造 `next[]` 与改进表，并解释线性复杂度。
- 掌握 Boyer–Moore 的坏字符和好后缀策略，能构造相应偏移表并分析字符集与模式分布的影响。
- 会为重复字符、周期串、匹配失败、空模式和边界位置设计测试。

### 树与搜索结构

- 掌握树、二叉树、完全/满树、深度、高度、规模之间的关系，以及先序、中序、后序和层次遍历。
- 能由合法的遍历序列重建二叉树，理解何时能够唯一确定；掌握迭代遍历的辅助栈不变量。
- 掌握 Huffman 树和编码的构造、前缀性质与加权路径长度。
- 理解 BST 的有序不变量、查找路径、插入和删除，能判断某个访问序列是否可能出现。
- 掌握 AVL 的平衡因子、单旋/双旋、插入与删除后的修复，以及高度的 Fibonacci 型界。
- 掌握伸展树的 `zig`、`zig-zig`、`zig-zag`，理解单次最坏时间和分摊 `O(log n)` 的区别。
- 掌握 B-树的阶、关键码范围、查找、上溢分裂和下溢合并/借位，并能估计高度和 I/O 优势。
- 掌握红黑树的颜色、根/叶、红色相邻限制和黑高度不变量，能模拟双红/双黑修复。
- 理解跳转表的随机层高、期望查找和局部操作，不把期望塔高与全表最大高度混淆。

### 优先级队列与堆

- 掌握完全二叉堆的数组映射、上滤、下滤、插入、删除和 `heapify`。
- 能用 Floyd 方法线性建堆，并逐轮完成原地堆排序；理解建堆和连续插入的复杂度差异。
- 比较二叉堆与多叉堆的高度、每层比较数和整体下滤成本。
- 掌握左式堆的空节点路径长度与左偏不变量，能用合并统一实现插入和删除最值。
- 理解胜者树/败者树、锦标赛模型和 Top-K 选择，能计算比较次数而不只给渐进量级。

### 散列、排序与选择

- 设计散列函数时考虑均匀性、固定点与高阶模式；理解除余法和 MAD 的差异。
- 区分开散列与闭散列，掌握线性、平方、双散列探查，以及表长和探查周期的关系。
- 正确处理装填因子、懒惰删除、探查终止、重散列和扩容，避免不存在关键码导致死循环。
- 比较起泡、选择、插入、归并、快速、Shell、堆和基数排序的时间、空间、稳定性和原地性。
- 掌握快速选择、中位数选择、众数/主流数等问题；能从目标 `K` 和输入分布选择全排序、堆或选择算法。

### 图与高级索引结构

- 掌握邻接矩阵、邻接表的空间差异，能正确维护顶点/边状态、发现和完成时间。
- 掌握 BFS、DFS，能分类有向图中的树边、前向边、后向边和跨边，并用时间戳证明关系。
- 理解优先级搜索框架，掌握拓扑排序、双连通分量、最小生成树和最短路径等典型应用。
- 能区分正权最短路、任意权路径和全源最短路所需条件；改变边权不一定保持最短路径树。
- 了解 `kd-tree`、range tree、interval tree、segment tree、priority search tree 的查询对象与空间代价。

## 🔍 核心分析方法

### 四层说明法

对任何结构或算法，都按以下顺序回答：

1. **接口契约**：输入、输出、前置条件、失败行为是什么。
2. **表示不变量**：内存中的哪些关系必须始终成立。
3. **正确性理由**：每一步为何保持不变量，终止时为何得到目标结果。
4. **成本模型**：执行了多少次基本操作，使用了多少额外空间。

例如，分析 AVL 插入不能只写“失衡后旋转”：要指出新节点必为叶、最低失衡祖先 `g`、`p` 与 `v` 的方向组合、旋转前后的中序次序、局部高度是否恢复，以及为何插入通常只需一次局部重构。

### 反例与边界

- 对绝对化命题，先尝试空结构、单节点、链、完全树、重复关键码、单调序列和最小环。
- 对随机或平均结论，先写清概率空间；“看起来随机”不等于均匀独立。
- 对开放寻址，必须验证探查序列能否覆盖所需桶位以及失败时一定停止。
- 对递归和循环，检查规模是否严格缩小、索引是否越界、相等元素是否造成停滞。
- 对图算法，检查有向/无向、连通性、负权、重边和自环等前提。

### 逐步模拟与证明相互校验

树旋转、堆排序、散列探查和 DFS 边分类适合先小规模手算，再用不变量解释；复杂度和通用正确性则不能由几个例子证明。考试中的手算表格是对机制的检查，最终应能从机制推导而不是背最终形状。

## ⚙️ 实现与验证要求

### 每类结构的最小实现

| 模块 | 至少实现 | 必须验证的不变量 |
| --- | --- | --- |
| 向量/列表 | 插入、删除、查找、遍历、旋转 | 秩/链接、长度、边界、所有权 |
| 栈/队列 | 入栈出栈、入队出队、表达式求值 | 顶/首尾位置、空满条件 |
| BST/AVL | 查找、插入、删除、旋转 | 中序有序、父子链接、平衡因子 |
| 堆 | 上滤、下滤、建堆、删除最值 | 完全形态、父子优先级 |
| 散列表 | 插入、查询、删除、重散列 | 探查可终止、关键码唯一、装填约束 |
| 图 | BFS、DFS、至少一种 PFS 算法 | 状态转换、边处理、距离/优先级含义 |
| 排序 | 至少三种不同范式 | 排列保持、有序性、稳定性声明 |

### 测试层次

- **示例测试**：复现讲义或试卷中的小规模过程。
- **边界测试**：空、一个元素、全部相等、已排序、逆序、极端关键码。
- **性质测试**：排序保持多重集合；旋转保持中序序列；堆删除序列单调；图遍历每个可达点恰被发现一次。
- **差分测试**：小规模随机输入与标准库或朴素算法比较。
- **压力测试**：链式 BST、聚集散列、稠密/稀疏图等最坏或退化输入。

## ✍️ 练习与考试方法

1. 先做[2011 期中题](exam/期中/2011数据结构期中考试题无答案版.docx)，逐题写出依据，再看解析。
2. 对 `next[]`、AVL/红黑树、堆排序、散列探查和 DFS 分类建立自己的逐步表格模板。
3. 判断题必须写“成立所需前提”或“最小反例”，不能只凭印象选择真假。
4. 复杂度题写出变量增长轨迹和求和式，区分紧界与仅成立的宽松上界。
5. 实现题先写 ADT 可用接口和不变量，再写伪代码；遵守题目给出的时间与附加空间约束。
6. 做完[2014 期末题](<exam/期末/DSA真题 - 2014期末.pdf>)与[2016 期末题](exam/期末/2016期末.pdf)后，按知识点而非按年份整理错题。
7. 最后使用未看答案的样卷限时模拟，复盘“概念错、机制错、计算错、边界漏、证明不完整”五类原因。
