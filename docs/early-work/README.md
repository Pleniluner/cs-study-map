### 统一学习循环

1. 先写对象、输入、输出、约束、单位、失败行为与验收标准。
2. 建立最小正确模型或基线，明确状态、不变量、定理条件或数据生成过程。
3. 独立推导或实现，再用手算样例、边界、反例、性质、差分或标准向量验证。
4. 只改变一个因素进行优化，记录复杂度、时间、空间、精度、吞吐、误差或用户指标。
5. 对失败定位到需求、表示、算法、实现、环境、数据、协议或评价层，而不是只修改最终输出。
6. 形成源码/推导、测试、原始数据、图表、复现步骤、决策记录、限制和后续问题。

### 程序设计基础

课程入口：[程序设计基础 README](<01_程序设计与软件工程/程序设计基础/README.md>)。

- **程序与类型**：源文件、头文件、预处理、编译、链接、`main`；`bool`、字符、整数、浮点、整除、取模、类型转换、优先级、短路求值；`long long` 的范围意识；整数溢出、浮点比较和 `sqrt` 边界。
- **控制与函数**：`if/switch/for/while`，循环不变量；函数职责、值/引用/指针传递；递归参数、基例、规模缩小、返回值和逐层展开；局部、全局、静态存储期与初始化。
- **数据表示**：一/二维数组的下标、布局、初始化和空间；`std::string` 的分类、反转、计数、模式验证、字段解析；旧字符数组容量和 `\0`；结构体、单链表查找/插入/遍历/释放；新代码优先 `vector/array/string` 与 RAII。
- **输入输出**：标准流、文件流、空白、换行、EOF、格式错误；成绩文件、数字文件、魔方输入与配置解析；失败信息和严格输出协议。
- **题型与算法**：完整枚举和布尔约束；事件顺序明确的模拟、矩阵、日期、星期、开关灯；素数试除/筛法、回文素数、友爱数、连续整数和、数制；IP 区间、大小写、区间压缩、替换密码、后缀排序；快速/归并排序及分区/合并不变量；错排、数塔 DP、快速倍增 Fibonacci；质数相邻网格、最大权二分匹配、角色分配和回溯；文件统计与稳定输出。
- **复杂度选择**：十万规模优先线性或 `O(n log n)`；短字符串可用直接比较；`n≤13` 可用位掩码指数搜索并剪枝；指数递归应转 DP；先实现最小正确基线，再测量优化。
- **魔方项目**：校验 `R/B/Y/G/O/W` 六面输入、九个同色、中心与对面关系；在外部面序和内部 `UFRDBL` 间集中映射；用六个 `3×3` 面或 54 贴纸表示状态并固定朝向；理解边翻转、角扭转和排列奇偶合法性。旋转应统一为置换，满足逆动作抵消、同面四转复原、半转两次复原和颜色计数不变。求解可按层目标、BFS/迭代加深/IDA*/模式数据库/两阶段法组织，必须有判重、父指针、路径重建、同面剪枝、资源上限、动作规范化与最终回放验证。
- **协作与质量**：结对中的驾驶员/领航员轮换；共享理解而非机械拆题；快速排序必须明确区间契约、进展和终止，覆盖空、单个、重复、已排序、逆序、负数和随机数据；开启警告、记录随机种子、分离调试输出。

- **排序与选择**：起泡、选择、插入、归并、快速、Shell、堆、基数的时间、空间、稳定和原地性；快速选择、中位数、众数/主流数；根据 K 和分布选择全排、堆或选择。
- **图**：邻接矩阵/表的空间；顶点/边状态、发现/完成时间；BFS、DFS 和树/前向/后向/跨边；优先级搜索框架、拓扑排序、双连通分量、MST 和最短路；区分正权、任意权、全源前提；边权变化不一定保留最短路树。
- **高级索引**：`kd-tree`、range tree、interval tree、segment tree、priority search tree 的查询对象和空间代价。
- **证明与测试**：循环/递归/结构不变量；空、单点、链、完全树、重复、单调序列和最小环反例；明确随机概率空间；检查递归规模、探查覆盖和图的有向/连通/负权/重边/自环前提。实现向量/列表/栈/队列、BST/AVL、堆、散列、图和三类排序；用示例、边界、性质、差分和退化压力测试。

### 形式语言、自动机与可计算性

课程入口：[形式语言与自动机 README](<02_算法、理论与编译/形式语言与自动机/readme.md>)。

- **基本对象**：有限字母表、串、长度、连接、幂、反向、前后缀/子串；区分空串 `ε` 与空语言 `∅`；语言并、交、差、补、连接、Kleene/正闭包；结构归纳与同态；区分表示语法和语言语义。
- **文法与推导**：`G=(V,T,P,S)`、直接/多步、句型/句子、最左/最右推导、分析树和果实；同串两棵不同树证明文法二义；区分文法二义和固有二义；优先级、结合性和最近 `else`；用双包含证明 `L(G)=L`。
- **Chomsky 层次**：3 型正规—有限自动机—有限状态；2 型上下文无关—PDA—一栈；1 型上下文有关—线性有界自动机—线性空间；0 型无限制—图灵机—递归可枚举。
- **正规表达式与有限自动机**：由 `∅/ε/字符/并/连接/闭包` 归纳构造 RE；DFA/NFA/ε-NFA 五元组、扩充转移和确定性；状态只保存奇偶、有限后缀、已见子串、模计数或违规等最少历史；DFA 转移完备并含死状态。
- **等价转换**：Thompson 构造 RE→ε-NFA；`ε-closure` 与子集构造 NFA→DFA；删不可达后用填表或等价类细分最小化；状态消去或路径迭代 DFA→RE。
- **正规性质**：并、交、补、差、连接、闭包、反向、同态、逆同态的构造性封闭证明；成员、空性、有限性、等价性，对称差空性；正规泵引理是必要非充分条件，严格遵循量词；能用闭包和已知非正规语言替代复杂泵引理。
- **CFG**：按递归、配对和分段设计并检查 `ε`/零次/最小次数；生成、可达、有用符号；按序消 ε、Unit、无用产生式；转 Chomsky Normal Form 并单独声明 ε；CYK 按区间长度/切分点维护可生成非终结符集合；区分可判定的成员/空性和一般不可判定的二义/等价。
- **PDA**：状态、输入、栈字母、转移和瞬时格局；终态接受 `L(P)` 与空栈接受 `N(P)`，一般 PDA 可互转；CFG→空栈 PDA，PDA→CFG 中 `[pXq]`；栈保存未匹配计数、待匹配符号、嵌套或阶段；DPDA 确定性及两种接受能力不等价；PDA 与 DFA 积证明 CFL∩正规仍 CFL。
- **CFL 性质**：并、连接、闭包、反向、同态、逆同态及与正规交；一般不对交、补、差封闭；CFL 泵引理 `z=uvwxy`、`|vx|>0`、`|vwx|≤n` 并覆盖所有分解；识别多重相等计数和复制语言 `ww` 超出单栈能力。
- **图灵机**：状态、输入/带字母、空白、转移、初态、接受和格局；扫描、标记、回退、复制、比较、二进制运算及停机证明；多带/多道/双向带/非确定 TM/栈机可模拟而不增强可计算性；从图说明语言并逐步模拟带和读写头。
- **可判定性**：识别器/判定器，RE/recursive，递归语言对补封闭；机器编码、通用语言、对角语言和停机；映射归约必须从已知难问题到目标；Rice 定理只适用 TM 所识别语言的非平凡语义性质，不套纯语法/步数；认识 PCP。
- **复杂性**：`P` 为确定性多项式；`NP` 为证书可多项式验证或非确定多项式；`NP-hard` 不要求在 NP；`NP-complete` 同时属于 NP 且 NP-hard；证明时先属于 NP，再从已知 NP-complete 归约到目标，方向不可反。
- **证明模板**：结构归纳、双包含、构造、反证/泵引理、归约；每题写清模型与接受方式、状态语义、边界串、转换中间表、量词和前提。

### 编译原理与 Decaf 编译器

课程入口：[编译原理 README](<02_算法、理论与编译/编译原理/readme.md>)。

- **阶段契约**：字符流→带位置 Token；Token→满足优先级/结合性的 AST；AST→完成名字/作用域/类型的带属性树；AST→保持求值/控制/检查语义的 TAC；TAC→基本块、CFG 和数据流固定点；优化 IR→遵守调用约定、布局和寄存器约束的目标表示。每阶段明确输入、输出、保证和错误责任。
- **表示层次**：CST 保留推导和标点，AST 去掉无后续意义的语法节点并直接表达结构；AST 适合静态语义，TAC 用临时、标签、跳转、参数、调用解耦源语言与机器；CFG、DAG、SSA 和机器指令服务不同分析。
- **词法**：关键字、标识符、十/十六进制整数、布尔、字符串、操作符、界符、空白、注释；正规式、有限自动机、最长匹配和规则优先；转义、未闭合字符串、换行、越界、未知字符及位置；Lexer 只分类词素，不承担上下文类型。
- **LL 分析**：`FIRST/FOLLOW/PS`、可空传播、开始符结束标记；消直接/间接左递归、提左因子并保持语言；预测表、栈模拟、递归下降、lookahead 和恢复；同一非终结符候选预测集互斥才 LL(1)。
- **LR 分析**：短语、直接短语、句柄、右句型和最右推导逆；增广文法、LR 项目、`CLOSURE/GOTO`、活前缀和项目集族；`ACTION/GOTO` 及移进/归约/接受/错误；比较 LR(0)、SLR(1)、LR(1)、LALR(1)，理解 FOLLOW、项目向前看和同芯合并；区分移进—归约与归约—归约，用文法、优先级、结合性或最近嵌套有依据消冲突。
- **AST 与恢复**：节点对应稳定语义概念并保存子节点、操作符和位置；列表用顺序集合，不保留人为二叉递归；以分号、右括号、语句/声明边界恢复并抑制级联；错误位置、次序和输出须确定可重复。
- **符号表与作用域**：记录名字、类别、类型、声明位置、作用域、可见性和存储；嵌套不交叉，进出栈并由内向外查找；全局、类、参数、局部、遮蔽、重复、先声明、关闭；类名、成员、静态/实例、继承、权限、覆盖和隐含 `this`；多遍先收集前向声明，再解析成员/体，最后检查表达式。
- **类型系统**：基本、数组、类、函数和错误类型；一/二元、赋值、条件、返回、索引、实参与形参、打印和对象创建；子类型、向上赋值、显式转换、覆盖签名和继承环；错误类型抑制级联但不伪装合法；为 `++/--`、`?:`、`numinstances`、串行卫士写静态规则和错误行为。
- **属性文法**：综合属性由子到父，继承属性由上下文/左兄弟进入；依赖图拓扑求值和循环检测；S 属性适合 LR 语义栈，L 属性适合左到右深搜并可变换；翻译模式动作只能访问已可用属性；能映射到递归下降参数/返回或 LR 栈偏移。
- **TAC 与回填**：常量、复制、算术逻辑、数组寻址、条件/无条件跳转、参数、调用、返回、标签；`Temp/Label`、求值顺序和副作用；布尔值表示或 `truelist/falselist`，语句 `nextlist`；短路、`if/else`、循环、`break`、三元和串行卫士避免重复求值；为除零、负长度、越界、空引用生成运行检查。
- **运行时存储**：代码、静态/全局、栈、堆的确定时间、管理者和生命周期；活动记录中的参数、返回地址、动态链、保存寄存器、局部和临时；动态链服务调用返回，静态链/Display 服务词法嵌套；caller/callee 保存、参数顺序、返回、SP/FP；固定局部可入栈，运行时数组/跨调用对象入堆。
- **数组与对象**：TAC 层基本值/引用固定字长；数组存长度并按元素宽度寻址、访问前检查；对象含 vtable 指针和按继承布局的字段，父布局兼容向上转型；父子相同方法槽，覆盖替换、新方法追加；实例方法有隐含 `this`，静态方法不经虚表；能画布局、虚表、调用和活动记录。
- **控制流**：首条、跳转目标、跳转后指令为领导者；基本块单入口出口；CFG 边准确；支配、回边 `n→d` 和自然循环，不把任意环当循环。
- **数据流**：到达定值前向 `GEN/KILL/IN/OUT`，活跃变量后向 `Use/Def/LiveIn/LiveOut`，可用表达式前向；写边界和转移，按 may 的并、must 的交迭代固定点；UD 从使用追定值，DU 从定值追使用；DAG 找公共子表达式、复制、无效定值和可重排计算，但尊重副作用与出口活跃。
- **后端**：指令选择考虑立即数、寻址和调用约定；按活跃区间构造冲突图并着色，同时活跃不可同寄存器；失败则 spill 后重分析；验证栈平衡、保存恢复、分支、参数、对象和错误路径。
- **Decaf PA**：PA1 用 JFlex/Flex、BYACC/J/YACC 实现词法、LALR(1)、优先级/结合性和 AST，并扩展自增减、三元、`numinstances`、串行条件/循环卫士；PA2 两趟建立符号表和类型检查；PA3 翻译 TAC、运行检查、数组、对象、vtable、隐含 `this` 和调用。后续贯通 CFG/数据流与后端。每次只加一个规则/访问器，以极小正反例、公开/隐藏回归和精确输出验证，不直接改生成文件。

- **学习问题**：监督/无监督，训练/验证/测试的职责；假设、损失、经验风险、泛化、偏差—方差、欠拟合和过拟合。
- **概率分类**：最大似然、MAP、Bayes；朴素条件独立、先验/条件概率、平滑、连续特征分布、缺失值和文本词项；使用对数概率防下溢。
- **经典模型**：决策树的信息增益、剪枝和不稳定；KNN 的距离、邻域和 K；线性/软间隔 SVM、对偶、核和支持向量；K-means 的交替优化、初始化、局部最优和距离。
- **集成**：Bagging bootstrap、加权多数；Boosting/AdaBoost.M1 的样本权、弱学习器误差、学习器权和投票；比较树/SVM 四种组合。
- **评价**：误差估计、置信区间、交叉验证，accuracy、precision、recall、F1；同一数据划分、特征、基学习器、预算和随机种子；报告不确定性而非单次最好值。
- **理论**：VC dimension、mistake bound 的含义和证明思路；概率图中的观测变量、条件独立与 d-separation。
- **朴素 Bayes 实验**：2017 Adult 数据含连续、类别、缺失，2018 中文垃圾邮件为词袋；比较 5%/50%/100% 训练规模并重复采样；处理零概率、Gaussian/离散估计和特定特征；不按最高准确率评分，而看实现、评价和分析。
- **集成实验**：WebSpam-UK2006 包含内容、degree、PageRank、TrustRank、truncated PageRank、supporter 特征；另有情感文本版本。分别固定数据、归一化、类别不平衡、特征子集，解释成功与失败。
- **方法**：每算法写输入、输出、目标、假设和复杂度；简单基线后逐项加平滑/特征/集成/调参；训练好测试差时排查泄漏、过拟合、分布偏移和度量；报告代码、设计、结果、讨论和复现环境。

### 信号处理原理

课程入口：[信号处理原理 README](<08_物理、电子与信号/信号处理原理/readme.md>)。

- **信号与系统**：classification、平移/伸缩/反转、奇偶分解、impulse、energy/power；检验 linear、time-invariant、causal、stable。
- **卷积/相关**：continuous/discrete convolution、impulse response、auto/cross-correlation；手算、图解和物理意义。
- **Fourier**：series、CTFT、duality/time-frequency shift/modulation/scaling/differentiation/Parseval，从定义推常见对。
- **采样**：impulse sampling、spectral replication、Nyquist、aliasing、anti-aliasing filter 和 ideal reconstruction；由带宽/调制画频谱并定最低采样率。
- **DTFT**：continuous periodic spectrum、symmetry、linear phase、difference property 和 frequency response。
- **DFT/FFT**：circular shift/convolution、leakage、picket-fence、resolution、zero padding；区分 DTFT 连续周期与 DFT 离散周期，补零不增加真实分辨；手算 4/8 点 radix-2 butterflies/twiddles 和运算量。
- **Z 与离散 LTI**：difference equation、system function、zeros/poles、ROC、inverse Z；由 ROC 唯一决定 left/right sequence，并判断 causal/stable。
- **filter**：FIR linear phase/symmetry、window main/side lobes；IIR Butterworth、bilinear transform、frequency warping/prewarping；从 specs 到 order、coefficients、response、implementation。
- **项目**：DTMF 生成和 FFT/Goertzel 双频识别，测噪声/时长/阈值；direct/circular/overlap-add/overlap-save convolution，验证分块边界和复杂度；FDM 的多路调制、载频间隔、filter、频谱和重建；STFT/iSTFT 与 wavelet 的 window time-frequency tradeoff。
- 统一记录输入、seed、sample rate、FFT length、window/filter specs、可手算样例、理论/数值误差、参数和关键图。
