# 计算机网络原理

*依据本目录的复习提纲、书面作业、滑动窗口/RIP/FTP 实验和路由器项目经验整理；目标是贯通“分层—协议—实现—测量—排错”。*

---

## 📋 课程定位

计算机网络原理研究不同主机与进程如何在不可靠、共享且异构的网络中通信。课程既包含分层、编码、介质访问、路由、可靠传输和应用协议，也要求把协议写成状态、报文格式、定时器和可执行程序。

学习每个协议时应回答五个问题：它向上提供什么服务、依赖下层什么能力、报文怎样编码、状态何时改变、发生丢包/重复/乱序或拥塞时怎样恢复。

## 🎯 应掌握的知识

- **体系结构**：协议、服务、接口、SAP、PDU/SDU、复用/分用，以及 OSI 与 TCP/IP 分层。
- **数据通信**：带宽与时延、波特率与比特率、奈奎斯特/香农上限、编码、调制和多路复用。
- **数据链路层**：成帧、CRC/海明码、停等、回退 N 帧、选择重传、HDLC/PPP 和协议状态机。
- **局域网**：ALOHA、CSMA/CD、以太网、MAC 地址、退避、交换机/网桥和生成树思想。
- **网络层**：IPv4/IPv6、子网与 CIDR、ARP/ICMP、最长前缀匹配、RIP/OSPF/BGP、隧道与拥塞控制。
- **传输层**：UDP/TCP 复用分用、序号与确认、重传、流量控制、连接状态机、RTT 和拥塞控制。
- **应用层**：客户/服务器、Socket、DNS、HTTP、FTP、电子邮件和网络管理。
- **工程能力**：字节序、校验和、报文解析、定时器、路由表、抓包、日志、测试拓扑与性能测量。

建议先做手算和状态图，再阅读代码。对滑动窗口、RIP 和 TCP 而言，如果不能在纸上推演报文、状态与定时器，调试时很容易只看到“包没到”，却不知道不变量在哪一步被破坏。

## ⚙️ 实验主线

### 协议机制实验

1. 用停等协议建立最小可靠传输，再扩展到回退 N 帧和选择重传。
2. 实现 RIPv2 报文检查、请求/响应、路由更新、不可达标记、定时通告和水平分裂。
3. 用 TCP Socket 构建简化 FTP，分别处理控制命令、数据连接、文件边界和错误返回。

### 路由器综合项目

原 README 记录了实验后来改为逐步构造路由器：基础收发、IP 转发、RIP、模块合并及路由表查询优化。实现时应保持框架接口稳定，先写最小端到端测试，再逐模块集成；最长前缀匹配可从线性基线开始，再用 trie 等结构评估查询速度与维护成本。

## 🔍 学习与调试方法

1. 为每层整理“服务、头部、状态、定时器、错误处理”五栏表。
2. 手算带宽时延积、窗口利用率、CRC、子网、最长前缀匹配和 TCP 拥塞窗口变化。
3. 抓包时从以太网帧逐层展开到应用数据，并检查长度、字节序、校验和与序号。
4. 为协议状态机建立事件—状态—动作—下一状态表，覆盖超时、重复和非法报文。
5. 分开测试报文编解码、表项更新、计时器和 I/O；最后再做多节点拓扑集成。
6. 记录可复现输入、预期包序列、实际包序列和最小失败场景，不以“最终 ping 通”代替验证。

## ⚠️ 归档与环境说明

- 目录同时包含 2016 协议机制实验和 2018 以后路由器项目说明，它们不是同一套连续工程，应分别学习。
- NetRiver、旧编译器、Windows Socket 或历史构建脚本可能无法直接在当前环境运行；请在副本中迁移并保留接口行为记录。
- 历年题跨度大，X.25、ATM、FDDI 等历史主题在不同年份权重不同；当前范围以正式教学要求为准。
- 原 README 的“早检查”“往年题较多”等内容是个人经历，不构成加分规则或考试预测。
- 旧实现和报告可能含边界处理、协议细节或表述错误。应以任务定义、报文规范和测试结果交叉验证。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 从应用数据开始画出逐层封装、寻址、转发和解封装过程。
2. 计算典型信道上限、窗口利用率、子网、路由匹配和 TCP 拥塞窗口。
3. 实现并验证一种滑动窗口协议，正确处理 ACK、超时、重复和序号回绕。
4. 解析与构造 IPv4/IPv6、UDP/TCP 或 RIP 报文，正确处理字节序与校验。
5. 维护路由表并解释 RIP、OSPF 和 BGP 在信息、收敛与适用范围上的差别。
6. 跟踪 TCP 连接建立、可靠传输、流量控制、拥塞控制和关闭状态。
7. 使用 Socket 完成一个可测试的客户/服务器程序或整合出最小路由器数据平面。
8. 用抓包、日志、状态表和自动化用例定位协议实现错误。
