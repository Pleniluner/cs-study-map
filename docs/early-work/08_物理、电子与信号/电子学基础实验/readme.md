## 🎯 掌握目标

- 安全、规范地使用直流电源、函数发生器、万用表和示波器；
- 能先估算量程和电路参数，再进行接线与通电；
- 理解变阻器两种接法及负载对分压关系的影响；
- 能从交流幅值、相位和频率测量反推 R、L、C 或等效阻抗；
- 能完成晶体管放大器偏置、波形观察和失真诊断；
- 能测量 RLC 幅频曲线、谐振频率、带宽和品质因数；
- 能记录原始数据、传播不确定度，并给出理论—实验偏差解释。

## ⚙️ 实验执行

### 通用流程

1. 根据原理图标注节点、电压极性和预计量级；
2. 断电接线并由同组同学交叉检查；
3. 先设限流和最小输出，再逐步增加激励；
4. 保存原始读数，不在记录阶段只写处理后的数；
5. 对关键点重复测量，说明仪器分辨率和读数方法；
6. 用理论曲线与实测曲线叠加比较；
7. 报告中区分随机误差、系统误差和操作失误。

### 分工原则

同组成员都应轮换完成接线、仪器调节、记录和计算。检查前每个人都必须能解释电路功能和当前旋钮的作用。

## 🔍 验证问题

- 三端变阻器作分压器和作可变电阻时，端子如何选择？
- 接入负载后输出电压为什么偏离空载分压关系？
- 示波器的峰值、峰峰值和有效值如何换算？
- 如何仅凭两路波形判断相位超前/滞后？
- 单管放大器的静态工作点过高或过低分别导致什么失真？
- 为什么 RLC 串联谐振时电流最大，而 L、C 两端电压可能很大？
- 如何由幅频曲线求谐振频率、带宽和品质因数？
- 哪些偏差来自仪器内阻、元件容差、寄生参数和接触电阻？
