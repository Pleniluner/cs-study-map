## 🎯 掌握目标

- 熟练进行布尔代数、最小项/最大项、卡诺图和 QM 法化简；
- 分析 TTL/CMOS 门、OC/三态门、扇出、延迟、竞争冒险；
- 设计译码器、编码器、选择器、比较器、加减法器和 ALU；
- 理解 ROM、PROM、PAL、PLA、PLD、FPGA 与存储器扩展；
- 掌握锁存器、RS/JK/D/T 触发器和建立/保持/传播延迟；
- 分析同步时序电路，写激励方程、状态方程、状态表和状态图；
- 从需求设计计数器、序列发生/检测器和控制 FSM；
- 检查自启动、非法状态恢复、竞争冒险和最大时钟频率。

## ⚙️ 设计训练

### 组合逻辑统一流程

1. 定义输入、输出和有效电平；
2. 写真值表与无关项；
3. 化简并比较门电路、MUX、译码器、PLA 等实现；
4. 估算门数、级数、扇出和传播延迟；
5. 检查竞争冒险和使能条件。

### 时序逻辑统一流程

1. 从需求画状态图并选 Moore/Mealy；
2. 合并等价状态、完成状态分配；
3. 根据触发器类型列激励表；
4. 化简激励/输出函数并画逻辑图；
5. 检查所有非法状态能否回到工作循环；
6. 用 `tCQ + tlogic + tsu` 计算最大时钟频率，并核对保持时间。

至少完成四种全加器实现：门电路直接实现、两个半加器级联、译码器/选择器实现、PLA/可编程逻辑实现，并比较资源和延迟。

## 🔍 复习与验证

- 能否不用背图，从真值表重新推导加法器、编码器和选择器？
- 能否解释普通门、OC 门和三态门的连接限制？
- 能否区分锁存器、主从触发器和边沿触发器的时序行为？
- 给定电路图，能否写出方程、状态表、状态图和波形？
- 给定序列需求，能否设计可自启动的发生器或检测器？
- 能否用不同触发器实现同一 FSM，并比较组合逻辑复杂度？
- 能否计算最大频率并检查建立、保持和门延迟？
- 能否从不可达状态推导最小修改，而不是只看工作循环？
