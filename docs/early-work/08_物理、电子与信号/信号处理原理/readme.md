## 🎯 掌握目标

- 熟练完成信号平移、伸缩、反转、奇偶分解、能量/功率判断；
- 理解冲激、卷积、相关和 LTI 系统之间的关系；
- 能推导并使用 Fourier 级数、连续时间 Fourier 变换及其性质；
- 能解释采样、频谱复制、混叠、抗混叠滤波与理想重建；
- 能区分 DTFT、DFT 和 FFT 的对象、周期性、采样关系与计算代价；
- 能用差分方程、单位冲激响应、系统函数和零极点分析离散 LTI 系统；
- 能由 Z 变换收敛域判断因果性、稳定性和序列形式；
- 能设计并比较 FIR/IIR 滤波器，并用 MATLAB 验证频率响应和实际效果；
- 能独立完成 DTMF 检测、快速卷积和频分复用项目。

## 📚 知识地图

| 模块 | 核心知识 | 必须会做的事 |
| --- | --- | --- |
| 信号与系统基础 | 分类、基本变换、冲激、能量/功率、LTI | 分解信号并检验线性、时不变、因果、稳定 |
| 卷积与相关 | 连续/离散卷积、冲激响应、自/互相关 | 手算、图解并解释物理意义 |
| Fourier 分析 | Fourier 级数、CTFT、对偶/平移/调制/尺度性质 | 从定义推导常见变换对并灵活用性质 |
| 采样与重建 | 冲激采样、频谱复制、Nyquist 条件、混叠、插值 | 画采样前后频谱并确定最低采样率 |
| DTFT | 频域周期性、线性相位、差分性质、频率响应 | 由序列或系统求频谱并判断对称性 |
| DFT 与 FFT | 圆周移位/卷积、频谱泄漏、栅栏效应、分辨率、基 2 FFT | 手算小规模 DFT，解释长度和补零的影响 |
| 离散 LTI 与 Z 变换 | 差分方程、系统函数、零极点、ROC、逆变换 | 根据 ROC 区分左右边序列并判断因果稳定 |
| 滤波器 | 频率选择性、FIR 窗函数、IIR Butterworth、双线性变换 | 从指标到阶数、系数、频响和实现 |
| 工程应用 | DTMF、长序列卷积、FDM、时频/小波 | 把理论映射到可测试的 MATLAB 程序 |

## 🔍 验证与复盘

- 能否从卷积定义推导 LTI 输出，并说明相关与卷积的差别？
- 能否不查表推导时间平移、频移、尺度、微分和 Parseval 性质？
- 给定带宽和调制结构，能否画出采样频谱并判断混叠？
- 能否解释 DTFT 连续周期、DFT 离散周期，以及补零为何不提高真实分辨率？
- 能否手算 4/8 点 FFT 并写清蝶形、旋转因子和运算量？
- 给定系统函数与 ROC，能否唯一确定冲激响应并判断因果稳定？
- FIR 线性相位的对称条件是什么，窗函数如何影响主瓣和旁瓣？
- 模拟 IIR 经双线性变换后为何会频率扭曲，如何预畸变？
- 历年卷中每个结论能否说明依据，而不是只记答案？
