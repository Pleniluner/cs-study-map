## 🎯 掌握目标

- 建立关联参考方向，正确处理电压、电流、功率和受控源；
- 熟练使用 KCL/KVL、节点电压法、回路电流法和等效变换；
- 掌握叠加、替代、戴维南、诺顿、特勒根和互易定理的条件；
- 用相量分析 RLC 正弦稳态、功率、谐振和频率响应；
- 用换路定律和三要素法处理一阶暂态；
- 掌握二极管、MOSFET、BJT 的大信号与小信号模型；
- 分析偏置、增益、输入/输出电阻、带宽、反馈和稳定性；
- 理解运放、差分级、电流镜以及基本 A/D、D/A 架构。

## ⚙️ 作业与仿真

### 作业使用法

1. 先按章节独立完成题目或教材对应习题；
2. 对照中文参考答案检查建模，再用英文教材答案补充不同写法；
3. 只把“首个错误步骤”记进错题表；
4. 48 小时后不看答案重做。

## 🔍 复习与验证

- 给定任意线性电路，能否在节点法、回路法、戴维南法中选择最短路径？
- 能否画相量图，并由图解释有功、无功和功率因数？
- 能否从换路前稳态得到 `0+` 初值，再写完整一阶响应？
- 能否先判断 MOS/BJT 工作区，再选择大信号或小信号模型？
- 能否从小信号等效图独立求增益、输入电阻和输出电阻？
- 能否解释负反馈如何改变增益、带宽、失真和阻抗？
- 能否从 Bode 图识别极点、截止频率和稳定性风险？
- 能否比较 Flash、流水线等 A/D 结构的速度和硬件代价？

期中与期末各至少做两轮：第一轮不限时查漏，第二轮闭卷限时验证。
