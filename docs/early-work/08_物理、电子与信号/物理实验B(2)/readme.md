## ⚙️ 实验方法

建议为每个项目建立一页“实验控制表”：

1. **问题与模型：** 要验证什么关系，模型有哪些近似？
2. **测量链：** 激励、被测对象、传感器、调理、采集和显示各是什么？
3. **参数设计：** 自变量范围、步长、采样率、重复次数和量程如何选？
4. **校准与对照：** 零点、背景、参考样品和仪器响应如何消除？
5. **数据处理：** 原始曲线如何变成斜率、峰间距、时间常数、磁滞面积或光谱参数？
6. **不确定度：** 主要误差通过哪个公式传到最终结果？
7. **反例检查：** 若交换接线、改变扫描方向或更换拟合区间，结论是否稳定？
8. **复现记录：** 报告是否足以让别人按相同条件重做？

## 🔍 验证与复盘

- 直流设计实验中，量程、灵敏度和元件功耗是否同时满足？
- 示波器测瞬态时，探头倍率、输入耦合、触发和采样率是否可解释？
- 导纳圆中的谐振/反谐振点如何识别，等效参数如何求得？
- 动态磁滞回线的两轴信号分别代表什么，积分环节为何必要？
- 弗兰克—赫兹曲线的相邻峰距如何关联激发电势，接触电势有何影响？
- 逸出功拟合选取的温区是否满足模型，温度测量误差如何传播？
- 干涉、衍射和吸收实验中，峰序/条纹序与波长标定是否可靠？
- 音频光纤链路能否分别解释发送、传输、接收端的失真与噪声？
