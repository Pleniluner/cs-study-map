## 🎯 掌握目标

学生最终应能够：

- 熟练使用矢量、微积分和曲线坐标表达运动；
- 从受力图出发处理平动、转动、滚动、碰撞和约束问题；
- 选择动量、角动量、机械能或广义功作为更高效的解题入口；
- 建立流体静力学、伯努利方程和理想气体过程模型；
- 在旋转参考系、复杂几何或陌生情境中保持符号和方向一致；
- 用英文清晰呈现假设、推导、单位与物理解释。

## ⚙️ 解题训练

每题至少完成两遍：第一遍独立建模，第二遍压缩成可复用的方法。

| 阶段 | 必做动作 |
| --- | --- |
| 读题 | 圈出对象、参考系、约束、初末状态和忽略项 |
| 建模 | 画受力图/过程图，定义坐标与正方向 |
| 求解 | 先列符号方程，再代数值；明确每条方程的对象 |
| 校验 | 检查量纲、方向、极限、数量级和能量来源 |
| 表达 | 用英文写出核心假设与物理解释 |
| 迁移 | 改变一个条件，判断原模型哪些部分仍成立 |

刚体和约束题应特别区分：质心加速度、接触点速度、角加速度和绳端速度；热学题应先规定“系统对外做功”或“外界对系统做功”的符号约定。

## 🔍 自测与复盘

- 能否在 3 分钟内完成受力图并确定最合适的守恒量？
- 能否解释为什么某一约束给出速度关系，而不是简单令两个速度相等？
- 能否从定义推导常见转动惯量、伯努利关系或绝热关系中的关键步骤？
- 能否识别旋转参考系中的惯性力，并说明纬度或方向的影响？
- 能否用同一组符号完整分析 P-V 图上的每一段过程？
- 能否不看手写答案重做一题，并指出原答案中的省略步骤？

每完成一套卷，统计“读题、物理、数学、计算、书写”五类失分；下一轮只针对最高频错误设计练习。
