## ⚙️ 实验方法

每个实验按同一套工作流完成：

1. **预习：** 写出原理图、关键公式、待测量、控制变量和风险点；
2. **设计表格：** 在动手前确定列名、单位、重复次数与量程；
3. **检查仪器：** 校零、校准、确认连接和工作范围，再开始正式采样；
4. **保留原始记录：** 不覆盖、不“修正”原始数据；修改处说明原因；
5. **现场快检：** 用量纲、数量级、趋势与重复测量发现接线或读数错误；
6. **数据处理：** 先画散点和残差，再选择逐差、拟合或线性化；
7. **结果表达：** 报告测量值、不确定度、单位和适当有效数字；
8. **讨论：** 解释主要误差来源、异常点、模型局限和可实施的改进。

## 🔍 验证与复盘

- 能否只看装置图，说出每个仪器的作用、量程和可能的系统误差？
- 原始数据是否包含单位、条件、序号和重复测量，而非只有处理后的结果？
- 是否能说明为什么选择逐差法、最小二乘或线性化，而不是机械套公式？
- 拟合后是否检查残差、截距、相关性和异常点？
- 间接测量的不确定度传播是否与函数关系一致？
- 分光计是否完成粗调、望远镜聚焦、平行光管调节和平台调平？
- 示波器测时间/相位时，触发、探头倍率和采样设置是否正确？
- 换一组数据后，能否不参考旧报告独立得到结论并解释差异？

## ⚠️ 资料边界与历史说明

- 目录中的主要材料是学生报告、原始数据和照片，不等同于当年课程的官方要求；实验参数应以实际仪器和教师说明为准。
- 同一实验存在多个版本和重复目录，例如“分/分2”“桥/桥2”“示声/示声2”“弦振动/弦振动2”；它们适合交叉核对，不应误当成不同实验。
- 文件含旧版 `.doc/.xls`、Mathcad、DWG、BMP 等格式，打开时可能需要兼容软件；转换格式前应保留原文件。
- 历届高分报告只能帮助理解结构和评分关注点，数据、图线和结论必须来自自己的实验记录。
