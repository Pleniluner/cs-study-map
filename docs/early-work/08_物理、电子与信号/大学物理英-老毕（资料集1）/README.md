## 🎯 掌握目标

完成本资料集后，应能够：

- 从英文长题干中快速提取对象、已知量、边界条件和所求量；
- 在热学、电磁学、光学和现代物理问题中选择正确的基本定律；
- 从对称性、守恒律或微元积分出发，而不是直接套最终公式；
- 对结果进行单位、极限、数量级和物理方向检查；
- 用简洁英文说明建模假设、关键步骤和最终结论。

## ⚙️ 练习方法

每道题统一采用以下六步：

1. 用一句中文和一句英文复述问题；
2. 画图并明确坐标系、正方向、系统边界和近似；
3. 写出使用的定律及其适用条件；
4. 先保留符号推导，再代数值；
5. 检查量纲、符号、极限和数量级；
6. 最后对照手写解答，记录“自己的方法—档案方法—更优方法”。

建议建立一张错题表：

| 字段 | 要记录的内容 |
| --- | --- |
| 题目 | 年份、阶段、题号和图片链接 |
| 模型 | 所属模块、关键定律、必要近似 |
| 失误 | 首个错误步骤及成因 |
| 修复 | 一句可执行的纠错规则 |
| 复测 | 3 天、1 周后是否能闭卷重做 |

## 🔍 自测与复盘

- **概念自测：** 能否不看公式表解释每条核心定律的对象和条件？
- **建模自测：** 面对新情境，能否先判断守恒量、对称性和状态变量？
- **数学自测：** 能否独立完成连续分布积分、微分近似和指数衰变计算？
- **表达自测：** 能否用英文写出 `Given / Model / Derivation / Check / Answer` 五段式解答？
- **限时自测：** 随机抽一套期中或期末题，在不看档案解答的情况下完成并复核。

复盘时优先比较“为什么这样建模”，不要只比较最后数值。

## ⚠️ 资料边界

- 资料主要是扫描图片和手写解答，缺少系统讲义、教材章节、作业序列和实验资料；概念学习必须另有教材支撑。
- 两次考试覆盖面不同，不能仅凭某一套卷推断完整教学大纲。
- 公式表为扫描件，搜索和复制不方便；建议自己重建一页公式体系，并为每个公式补上条件。
- 成绩分布图片不反映个人知识掌握情况，不应据此调整学习优先级。
- 手写答案可能有近似、笔误或跳步；任何结果都应自行做量纲和极限检查。
