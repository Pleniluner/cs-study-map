## 🎯 掌握目标

- 能从库仑定律和叠加原理求离散/连续电荷的场；
- 能根据对称性正确使用高斯定理、安培环路定理；
- 能把电势、场强、功、能量和电容联系起来；
- 能处理导体、电介质、磁介质中的场与边界条件；
- 能分析带电粒子、载流导线和电流回路所受磁力；
- 能使用法拉第—楞次定律、自感互感与场能观点；
- 能理解 Maxwell 方程组如何统一静电、稳恒电流、静磁、电磁感应和电磁波。

## 📚 知识地图

| 模块 | 核心知识 | 常见检查点 |
| --- | --- | --- |
| 静电场 | 库仑定律、叠加、场线、连续分布积分、高斯定理 | 对称性是否足以把场强提出积分号 |
| 电势 | 电势差、势能、泊松/拉普拉斯思想、等势面 | 路径无关和参考零点是否明确 |
| 导体与电介质 | 静电平衡、镜像/边界、极化、电位移、电容 | 自由电荷与束缚电荷是否区分 |
| 稳恒电流 | 电流密度、连续性、欧姆定律、焦耳热 | 局部形式与电路形式是否混淆 |
| 真空磁场 | 毕奥—萨伐尔、安培定理、磁通量 | 电流方向和积分路径方向是否一致 |
| 磁力 | 洛伦兹力、带电粒子轨道、导线受力、磁矩 | 速度分量和右手定则是否正确 |
| 磁介质 | 磁化强度、磁场强度、磁导率、边界 | `B、H、M` 的角色是否区分 |
| 电磁感应 | 动生/感生电动势、楞次定律、自感互感、磁能 | 回路方向、磁通符号和能量来源 |
| Maxwell 与电磁波 | 位移电流、积分/微分形式、电磁波传播与能流 | 静态定律如何成为完整方程组的一部分 |

章节顺序应与复习概要一致：静电场 → 电势 → 导体 → 电介质 → 稳恒电流 → 磁场和源 → 磁力 → 磁介质 → 电磁感应 → Maxwell 方程组和电磁波。

## ⚙️ 练习方法

每道场论题先回答四个问题：

1. **源是什么：** 电荷、电流、变化磁通还是边界条件？
2. **对称性是什么：** 球、柱、平面，还是没有足够对称性？
3. **求解工具是什么：** 直接积分、高斯/安培定理、电势法或能量法？
4. **方向和边界是什么：** 法向、环路方向、参考零点和介质界面如何定义？

建议按“题目 → 独立推导 → 单位/极限检查 → 对照答案 → 变式重做”使用章节 DOC。答案中若跳过矢量方向或边界条件，应自行补全。

## 🔍 复习与验证

- 能否从高斯定理推导球、柱、平面对称场，而不是背结果？
- 能否由电势求电场，并解释导体表面和介质界面的条件？
- 能否用毕奥—萨伐尔与安培定理分别求解并说明适用场景？
- 能否画出带电粒子在均匀电磁场中的轨迹并判断能量变化？
- 能否区分动生电动势与感生电场，并用楞次定律判断方向？
- 能否写出 Maxwell 四方程的积分形式、物理意义和静态极限？
- 能否在一张图上串起“源 → 场 → 力 → 能量 → 波”？
