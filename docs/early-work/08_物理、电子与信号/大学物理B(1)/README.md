## 🎯 掌握目标

- 能从运动描述过渡到牛顿定律、守恒律和转动方程；
- 能处理多物体、变力、非惯性参考系、约束和碰撞问题；
- 理解狭义相对论的时空变换、速度变换与相对论能量；
- 建立简谐振动、波动传播、干涉、驻波和多普勒模型；
- 从微观统计和宏观状态两条线理解热学与热力学；
- 能把公式的来源、成立条件和适用对象说清楚，而不是只记结论。

执行建议：

1. 先读质点力学提纲，自己重画“力—冲量—功—力矩”关系图。
2. 用期中题库完成质点、刚体和相对论的首次闭环。
3. 依次完成振动、机械波、热学题库；每章先做题，后看答案。
4. 把 [讨论课题目](exam/讨论课/讨论课题目.pdf) 当作章节间综合练习。
5. 最后用期中/期末资料限时自测，再决定是否进入光学、量子扩展题。

## ⚙️ 练习与推导

每个模块至少形成三类产出：

- **概念卡：** 定义、物理图像、适用条件、常见误区；
- **推导卡：** 从基本定律到常用结果的最短可靠路径；
- **原型题：** 一个代表模型及其可变化的条件。

重点训练：

| 模块 | 必做训练 |
| --- | --- |
| 力学 | 受力图、参考系、守恒量选择、多物体约束 |
| 刚体 | 平动与转动分离、平行轴定理、瞬时转轴、滚动条件 |
| 相对论 | 事件坐标表、变换方向、固有时/固有长识别 |
| 振动波动 | 初相判定、波函数方向、能量流、干涉/驻波条件 |
| 热学 | 状态量与过程量、P-V 图、循环方向、熵变和效率 |

## 🔍 复习与验证

- 闭卷画出质点力学线索图，并说明每条守恒律的成立条件。
- 随机抽取一道刚体题，分别尝试牛顿—欧拉法和守恒法。
- 对相对论题先明确哪个量是固有量，再写洛伦兹变换。
- 从振动方程独立画出位移、速度、加速度和能量随时间变化。
- 从波形图判断传播方向、质元速度和相位差。
- 对任一热力学循环逐段列出 `Q、W、ΔU、ΔS` 的符号。
- 完成一套综合卷后，按“概念、模型、数学、计算、表达”统计错误。

## ⚠️ 资料边界

- 目录没有连续课件或教材，主要是试题、答案和讨论课照片；首次学习需配合教材。
- `exam/题库` 同时包含 B(1) 与后续光学/量子内容，复习时不要把它们混成一个阶段。
- 多份 DOC/DOCX/PDF 内容重复，照片答案清晰度不一；应按主题选一份主材料，其他只做交叉核对。
- RAR/ZIP 是历史压缩包，使用前需先确认内容与解压环境；无需为了完成核心课程全部展开。
- 题库答案是校验工具，直接阅读会掩盖建模薄弱点。
