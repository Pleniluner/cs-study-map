# 清华大学计算机知识探索教材

这是依据上级目录《清华大学计算机知识探索总图》编写的模块化 LaTeX 教材工程。第一卷先解决三个问题：每门课程究竟要掌握什么、做到什么才算学会、怎样一步步留下可验证的学习证据；随后再用跨课程路线把全部知识连成系统。

工程结构借鉴 [jamesfang8499/math4](https://github.com/jamesfang8499/math4) 的组织方式：由 `main.tex` 统一设置版式并装配前言和编号章节，每章保存在独立的 `.tex` 文件中。这里只借鉴工程组织和“正文—例证—练习”的教材思路，全部计算机内容均依据本地课程资料重新撰写。

## 文件结构

- `main.tex`：总入口、版式、课程环境和整书装配。
- `preface.tex`：教材目的、覆盖范围和使用方法。
- `1.tex`：学习定义、总知识图和统一验收方法。
- `2.tex`：程序设计、软件工程与数据库。
- `3.tex`：算法、形式理论与编译。
- `4.tex`：计算机系统、体系结构与嵌入式。
- `5.tex`：网络、密码学与安全。
- `6.tex`：人工智能与数据科学。
- `7.tex`：图形、图像、多媒体与人机交互。
- `8.tex`：数学基础。
- `9.tex`：物理、电子、数字逻辑与信号。
- `10.tex`：跨域联系、项目阶梯和最终学习验收。
- `expanded/`：按知识依赖顺序逐门增加的详细教材正文；由对应课程章节直接装配。
- `main.pdf`：编译后的整书。

## 编写状态

第一卷覆盖总 README 中的 60 门实质课程。每门课程均含四个固定部分：

1. 具体掌握：完整列明对象、概念、方法、实验与边界。
2. 完成标准：用可检查的作品、推导、测试或实验说明何时算学会。
3. 具体做法：给出从最小模型到综合项目的学习步骤。
4. 知识联系：说明前置知识、并行课程和后续用途。

详细正文采用“概念解释—推导—例题—实验—练习—答案提示—阶段验收”的统一结构，而不是另起一套互不相连的目录。

当前已完整展开：

- `expanded/2-1-programming-foundations.tex`：程序设计基础正文，共十三个教学单元，从构建链、类型、控制流、函数递归、数据表示和文件协议，推进到排序、动态规划、搜索、工程验证与魔方综合项目，并给出分阶段作品、综合练习库和最终达标线。

## 编译

本稿已使用 Tectonic 0.16.9 实际编译验证。安装 Tectonic 后可直接运行：

```text
tectonic main.tex
```

也可以使用 XeLaTeX：

```text
xelatex main.tex
xelatex main.tex
```

第一次生成目录和交叉引用，第二次稳定页码；也可以使用 `latexmk -xelatex main.tex`。

## 内容边界

教材综合的是本地 Readme 中的知识与项目要求，不复制原课件、教材或学生答案。历史工具、数据集、SDK 和第三方材料仍受各自许可约束；安全实验只能在书面授权和隔离环境中开展。
