# 模式识别

*本目录保存一套 2018 年 Homework 1–10 的连续作业、推导、源码和实验图；学习主线从形状特征、贝叶斯决策一直延伸到 HMM、聚类、神经网络和深层表示。*

---

## 📋 课程定位

模式识别研究如何把原始观测变成可判别表示，并依据统计模型或判别函数做分类、聚类和序列推断。本目录没有完整讲义或试卷，但十次作业构成了清晰的能力阶梯：先表示对象，再建立概率决策规则，估计未知参数，最后比较非参数、线性、序列和神经网络方法。

学习每一种方法时都要区分四件事：特征如何得到、模型作了什么假设、参数怎样学习、结果怎样验证。

## 🎯 应掌握的知识

- 形状参数、轮廓函数、矩、傅里叶描述子等特征，以及平移/旋转/尺度不变性与抗噪性。
- 贝叶斯最小错误率、最小风险、损失矩阵、似然比检验和拒识规则。
- 多元高斯分布、协方差结构、判别函数和二次/线性决策面。
- 最大似然、MAP、贝叶斯参数估计和估计偏差/方差。
- 离散贝叶斯模型、条件独立及贝叶斯网络的因子分解。
- 马尔可夫链、HMM、前向/后向、Viterbi 和序列概率。
- KNN、感知器准则、线性分类器与非线性特征映射。
- K-means、无监督参数估计和类似 EM 的交替估计思想。
- MLP、Sigmoid、反向传播、多类输出编码和训练/测试评价。
- 自编码器、RBM、逐层预训练、展开与微调的基本思想。

## ⚙️ 作业复现方法

### 推导类作业

先写随机变量、类别、先验、似然和损失的定义，再划分决策区域。遇到高斯模型时，明确均值、协方差是否相同以及先验是否相等；这些假设直接决定决策面是线性还是二次。

### 编程类作业

1. 固定随机种子并保存生成数据。
2. 用少量样本手算判别值、一次参数更新或一轮聚类。
3. 将数据生成、训练、预测和评价拆成独立函数。
4. 同时报告各类别和总体结果，避免类别不均衡掩盖失败。
5. 改变一个参数后重跑同一数据，解释 K、初始化、网络结构或迭代次数的影响。
6. 为 HMM 和神经网络检查数组形状、归一化、数值稳定性与终止条件。

## 🔍 比较框架

| 维度 | 需要回答 |
|---|---|
| 表示 | 使用原始坐标、手工特征还是学习到的表示？ |
| 假设 | 高斯、独立、线性可分、局部平滑或马尔可夫性是否合理？ |
| 学习 | 有监督、无监督还是隐变量交替估计？ |
| 决策 | 后验最大、风险最小、最近邻、判别函数还是聚类分配？ |
| 复杂度 | 训练和预测随样本数、维数怎样增长？ |
| 评价 | 是否使用独立测试集、分类别指标和重复实验？ |

完成十次作业后，应能够解释“同一组数据为何被不同方法分成不同结果”，而不只比较最终正确率。

## ⚠️ 归档使用说明

- 目录主要是一名学生的 2018 作业提交，不是官方讲义、标准答案或完整实验包。
- 同一题目常同时保存 tex、pdf、图片、压缩包和可执行文件。以可读源文件为主，历史 exe 不保证安全或兼容，建议不要直接运行。
- 部分中文文件名出现编码损坏的副本，内容可能是编辑器产生的临时文件；无需为学习而修复或删除。
- 作业报告中的数值依赖随机数据和实现细节，必须重新运行并核对，不能视为预期标准。
- Homework 8 中的“无监督 MLE”应结合隐变量交替估计理解；复现时写清分配与参数更新步骤。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 为图形或数值样本选择特征，并说明不变性、判别性和鲁棒性的取舍。
2. 从先验、似然和损失推导贝叶斯分类器与决策边界。
3. 对多元高斯、离散概率和 HMM 完成参数估计与推断。
4. 实现并比较 KNN、线性分类器、K-means 和无监督参数估计。
5. 从零实现最小 BP 网络，并用有限差分或手算检查局部梯度。
6. 解释自编码器、RBM 预训练与微调在表示学习中的作用。
7. 用统一数据划分和指标完成多方法比较，并说明模型假设失败时的现象。
