# 搜索引擎技术基础

*依据本目录的性能评价、PageRank、图片搜索和校园搜索工程整理；目标是贯通抓取、解析、索引、排序、评价与交互的完整信息检索流水线。*

---

## 📋 课程定位

搜索引擎是一个系统工程：离线端持续获得和处理文档，建立倒排索引与链接特征；在线端解析查询、召回候选、计算相关性、排序并展示；评价端通过人工相关性标注和指标发现问题。

现有资料包含三次小作业和一次课程设计的完整痕迹，适合按“先度量现有搜索—再理解链接/内容排序—最后搭系统”的顺序学习。

## 🎯 应掌握的知识

- 信息需求与导航类、信息类、事务类查询；query、document、relevance 的关系。
- 爬虫的种子、frontier、范围/URL 过滤、抓取礼节、格式识别、编码和失败重试。
- HTML/PDF/Office 文本与元数据解析、去噪、字段化和统一文档表示。
- 中文分词、词项、词频、文档频率、倒排表和索引的构建/更新。
- 向量空间模型、TF-IDF、BM25、字段权重、文档长度和多词查询。
- Web 图、入/出链接、PageRank、阻尼、迭代收敛和与内容相关性的融合。
- precision、recall、P@k、AP/MAP、RR/MRR、pooling 和相关性标注。
- 图片描述文本扩展、标签索引，以及内容缺失时的检索局限。
- Lucene 的 Document/Field/Analyzer/IndexWriter/Query/IndexSearcher 等角色。
- 查询提示、拼写纠错、高亮、预览、语音输入和相关推荐等交互功能。

## ⚙️ 四个项目主线

### 性能评价

先写查询的信息需求，再构造热门/冷门和不同类型查询；对 pooling 中每个结果独立标注相关性。根据需求选择指标：导航查询更关注第一个相关结果，信息查询更关注前若干结果整体质量。报告必须保留查询、结果、标注和计算过程。

### PageRank

把 URL/词条映射为稳定整数 ID，构建出边和入边，处理无出链节点，迭代到明确阈值。除了排名，还要检查概率和、残差、迭代次数、度分布、异常节点以及 PageRank 与入度的关系。

### 图片搜索

先用标签建立可工作的基线，再加入网页 title/文本扩展描述。分别实现或验证 VSM 与 BM25，检查中文查询分词、多词组合、索引路径和页面展示，并用固定查询集比较扩展前后。

### 校园搜索

按小数据闭环推进：少量授权网页抓取 → 统一 JSON/文档表示 → 分词和倒排索引 → 基本查询 → 排序 → 页面展示 → PageRank/字段权重 → 纠错等扩展。任何阶段失败都能用小样本定位，而不是先抓取大规模数据。

## 🔍 工程与评价方法

1. 为每个文档保留 URL、抓取状态、编码、标题、正文、锚文本、结构字段和更新时间。
2. 将抓取、解析、建索引、检索和 Web 服务拆成可重复运行的阶段。
3. 建立十几个可人工判断的小查询集，覆盖导航、信息、事务、错别字和无结果。
4. 先评估默认排序，再逐项加入字段 boost、PageRank 或文件类型规则。
5. 每次改动同时观察 MAP/P@10/MRR、延迟、索引大小和失败查询。
6. 对坏结果定位到召回、分词、字段、相关性公式、链接分数或界面层。
7. 对查询提示/纠错等功能测试正确建议、无建议、中文/英文和未知词。

## ⚠️ 归档、兼容与抓取边界

- 工程使用较早的 Heritrix、Lucene 3.5、IKAnalyzer、Tomcat/JSP 和 Java 依赖，当前环境通常需要隔离和版本锁定；不要随意替换单个 jar。
- 目录含 war、jar、Lucene 索引段、IDE/SVN 元数据和旧前端依赖。它们是历史产物，不应直接部署到生产或暴露公网。
- 原 README 记录了“三次小作业、一次大 Project”、点名和随堂测验等个人经验；这些不代表当前课程安排或评分规则。
- 原经验提到大规模校园抓取，但实际复现必须遵守当前授权范围、robots/站点政策、速率限制和存储预算。优先使用已提供语料或小型自有站点。
- 历史报告中的数据规模和指标只描述一次归档实验，不能作为当前系统性能基准。
- 课程提交代码可用于理解架构，但应重新检查编码、路径、异常处理、资源关闭和安全性。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 从查询需求建立相关性标注集，并正确计算 P@k、AP/MAP 和 RR/MRR。
2. 解析并字段化多种文档，完成中文分词、倒排索引和基本查询。
3. 实现或解释 TF-IDF/VSM 与 BM25，分析字段权重和长度归一化。
4. 从链接图计算 PageRank，验证收敛并分析与入度/语义的关系。
5. 在授权小语料上完成抓取—预处理—索引—检索—展示的端到端系统。
6. 将 PageRank、查询纠错、高亮或推荐等至少一种扩展接入并做消融评价。
7. 交付可复现的环境、命令、数据说明、测试集、指标、失败案例和已知限制。
