# 机器学习概论

*依据本目录的书面作业、朴素贝叶斯与集成学习实验、部分课后题答案和历年题整理；目标是贯通“建模假设—学习算法—泛化评价—实验解释”。*

---

## 📋 课程定位

机器学习不是把数据交给一个现成模型后只看准确率，而是从任务、数据和假设空间出发，选择学习方法，估计其泛化能力，并用可复现实验解释结果。

本目录同时呈现三条主线：

- 理论主线：有限样本学习、过拟合、假设评价、置信区间、VC 维和错误界。
- 方法主线：KNN、决策树、朴素贝叶斯、SVM、聚类、Bagging 和 AdaBoost。
- 实验主线：从原始属性或文本构造特征，处理缺失/连续值与类别不平衡，再进行训练、评价和误差分析。

## 🎯 应掌握的知识

- 监督、无监督学习的任务定义，以及训练集、验证集和测试集的职责。
- 假设、损失、经验风险、泛化误差、偏差—方差、欠拟合与过拟合。
- MAP、最大似然与贝叶斯分类；朴素条件独立假设、平滑和连续特征建模。
- 决策树的信息增益、剪枝与不稳定性；KNN 的距离、邻域和 K 值选择。
- 线性与软间隔 SVM、对偶问题、核方法及支持向量的含义。
- K-means 的交替优化、初始化、局部最优，以及聚类距离的选择。
- Bagging、Boosting、加权多数和 AdaBoost.M1 的样本/学习器权重更新。
- 误差估计、置信区间、交叉验证，以及 accuracy、precision、recall、F1 等指标。
- VC 维、mistake bound 等学习理论概念及其证明思路。
- 概率图模型中的条件独立、观测变量与 d-separation 基础。

先修建议为概率统计、线性代数、微积分和至少一种编程语言。

## ⚙️ 两组实验主线

### 朴素贝叶斯

| 问题 | 必须处理 |
|---|---|
| 数据 | 解析标签与属性；区分连续、类别、缺失值或文本词项 |
| 估计 | 先验、条件概率、连续分布参数和对数概率 |
| 零概率 | 平滑策略及参数的影响 |
| 数据规模 | 5%、50%、100% 等训练比例，多次随机采样 |
| 评价 | 测试集隔离、均值/范围及分类指标 |
| 分析 | 错误样本、特征选择和假设不成立的情形 |

### 集成学习

至少比较 Bagging + 决策树、Bagging + SVM、AdaBoost + 决策树、AdaBoost + SVM。应自己实现集成层，明确 bootstrap、样本权重、弱分类器误差和最终投票；基学习器可以复用，但要固定接口和参数。

比较时同时控制数据划分、特征、基学习器参数和随机种子。类别不平衡、归一化和特征子集要作为独立变量，不应和算法切换混在一次实验中。

## 🔍 理论与评价方法

1. 为每个算法写出输入、输出、优化目标、关键假设和计算复杂度。
2. 推导题先写概率或优化问题，再说明每一步使用的条件。
3. 模型比较必须在同一数据划分上完成，并报告随机性和不确定性。
4. 优先建立简单基线，再增加平滑、特征、集成或调参。
5. 对训练好、测试差的现象从数据泄漏、过拟合、分布偏移和度量选择排查。
6. 设计题要覆盖特征、标签、算法、训练/验证、指标、部署反馈和局限。

历年题中的结论或证明记录可能不完整，应以题目本身为训练对象，答案用于发现遗漏而非直接记忆。

## ⚠️ 归档使用说明

- 资料跨 2017、2018 等年份，同一实验的数据集和评价方式不同；不要把两个版本的要求混成一次提交。
- 目录含 class、jar、IDE 配置、截图、pages 和 rar 等历史产物。它们不证明当前环境可复现，应从源码与说明重新建立环境。
- 某些数据体量较大或未完整归档。先用小样本验证读取、概率和评价流程，再扩大规模。
- 课后答案和实验报告属于参考样例，可能包含错误、环境依赖或不充分结论；使用前应重新计算。
- 历年题只代表旧年份，不可据此推断当前考试范围、形式或原题。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 将一个实际问题定义为特征、标签、损失、数据划分和评价指标。
2. 从零实现朴素贝叶斯，正确处理平滑、连续/缺失特征与对数概率。
3. 解释并比较 KNN、决策树、SVM、K-means、Bagging 和 AdaBoost 的假设与适用情形。
4. 推导软间隔 SVM 对偶、典型误差界或置信区间，并说明结果含义。
5. 设计无数据泄漏、可重复且包含不确定性的模型比较实验。
6. 根据错误样本、学习曲线和指标差异提出可验证的改进假设。
7. 写出包含基线、控制变量、原始结果、分析和局限的完整实验报告。
