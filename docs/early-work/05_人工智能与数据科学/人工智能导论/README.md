# 人工智能导论

*依据本目录的课程总结、历年题记录、习题汇编，以及拼音输入法和重力四子棋报告整理；主线是“状态空间搜索—博弈—学习—逻辑推理—不确定性系统”。*

---

## 📋 课程定位

人工智能导论建立的是方法地图：面对一个问题，先决定如何表示状态与知识，再选择搜索、优化、概率学习或逻辑推理方法，最后说明正确性、效率和不确定性。

本目录理论资料以复习总结和旧试题为主，实践资料则展示了两种典型系统：用语言模型/Viterbi 完成拼音到汉字解码，用 UCT/MCTS 完成重力四子棋决策。

## 🎯 应掌握的知识

- 状态空间、产生式系统、OPEN/CLOSED 表、宽度优先、深度优先和回溯。
- A、A*、IDA*、AO* 的节点选择、代价函数、可采纳性和启发函数单调性。
- 极小极大、估价函数、α-β 剪枝，以及 MCTS/UCT 的选择、扩展、模拟和回传。
- 爬山、模拟退火和遗传算法的表示、邻域、接受概率、选择、交叉与变异。
- 朴素贝叶斯、决策树、信息熵/增益、线性/核 SVM 的导论级原理。
- 一阶谓词逻辑、Skolem 化、子句集、归结、问题回答和产生式推理。
- 正向/逆向演绎、解图一致性、语义网络和专家系统的解释机制。
- 不确定性推理中的置信度/CF 组合及其假设。
- HMM、n-gram、平滑和 Viterbi；MCTS 的探索—利用权衡。

## ⚙️ 必会手推任务

### 搜索与博弈

- 在给定图上逐步记录 OPEN、CLOSED、g、h、f、父节点和扩展次序。
- 为 A* 设计启发函数，分别证明非高估与单调条件，区分找到目标与确认最优的终止条件。
- 在 AND/OR 图上执行 AO*，维护局部解图和代价回传。
- 对博弈树从左到右执行 α-β 剪枝，标出 α、β、倒推值和被剪分支。
- 对一次 UCT 迭代写出选择、扩展、随机模拟和回传后访问/收益变化。

### 逻辑与不确定性

- 将谓词公式消去蕴含、前束化/Skolem 化并化为子句集。
- 用归结证明目标，再修改证明树提取变量回答。
- 分别画正向和逆向演绎的解图，检查是否一致。
- 按给定规则逐步组合 CF，不在缺少独立性或规则语义时直接套公式。

## 🔍 两个 Project 的学习重点

| Project | 核心模型 | 必做验证 |
|---|---|---|
| 拼音输入法 | 字/词状态、n-gram 转移、平滑、Viterbi 与回溯 | 单字/整句正确率、未知组合、速度、不同阶数和参数 |
| 重力四子棋 | 状态节点、合法动作、终局判断、UCT 与 rollout | 固定时间/迭代预算、不同对手、先后手、胜平负统计 |

输入法中要用对数概率避免长序列下溢，并明确平滑、候选保留和语料切分。棋类系统中要保证回传时玩家视角一致，避免把对手收益错误地当成己方收益。

## ⚠️ 归档使用说明

- 大量“真题”是学生回忆或论坛转存，可能缺题、记错数字或混合不同卷；只能用于练习算法步骤。
- 旧资料多次说明某一年“重点”发生变化，因此不能根据频率推断当前考试范围。
- 部分文本含已失效外部链接、乱码或非正式讨论。关键定理和公式应回到课程材料重新确认。
- 两份 Project 报告只有思路与结果，没有完整源码或数据。README 不据此补造实现细节。
- 练习时应独立手推搜索顺序、剪枝和归结，再用现有答案核对；直接背节点次序无法迁移到新图。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 将实际问题表达为状态、操作、目标、代价和启发函数。
2. 手工执行 BFS/DFS/A*/AO*，并说明 A* 最优性的条件。
3. 正确执行极小极大、α-β 和一次完整 MCTS/UCT 迭代。
4. 设计模拟退火或遗传算法的表示、邻域/交叉、参数和终止条件。
5. 完成一个小型贝叶斯、决策树或 SVM 推导，理解其在 AI 方法图中的位置。
6. 将谓词公式化为子句集，完成归结、问题回答和正/逆向演绎。
7. 设计并评价一个 Viterbi 输入法或 MCTS 棋类系统，报告正确性、效率和失败案例。
