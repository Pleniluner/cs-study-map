## 📋 课程定位

数据挖掘关注如何从大量、异构和可能有噪声的数据中发现可解释、可验证的模式。现有题目横跨数据仓库与 OLAP、数据预处理、频繁模式、分类、聚类、序列/XML/Web 挖掘和评价指标，说明课程既要求概念，也要求手算算法与模式设计。

## 🎯 应掌握的知识

- KDD/数据挖掘流程：问题定义、清洗、集成、变换、挖掘、评价与呈现。
- 描述统计、五数摘要、方差、分箱平滑、归一化、缺失/异常值处理。
- 相似度与距离：Euclidean、Manhattan、相关性及 metric 的基本条件。
- 数据仓库、事实表、维表、概念层次、星型模式、数据立方体和 cuboid。
- OLAP 的 roll-up、drill-down、slice、dice、pivot，以及 OLTP/OLAP 区别。
- Apriori 向下闭包、候选生成、FP-tree/FP-growth、diffset 与约束推动。
- support、confidence、lift、all-confidence，以及 closed/maximal 频繁模式。
- 决策树、信息熵/增益、gain ratio、Gini、朴素贝叶斯、SVM、感知器和集成学习。
- K-means、K-medoids、BIRCH 等聚类方法及初始化、异常值和簇数问题。
- 序列模式、周期模式、XML/Web 挖掘和分类评价的导论概念。

## ⚙️ 必会手算与设计

| 类型 | 必会任务 |
|---|---|
| 预处理 | 排序后算五数摘要；等频/等宽分箱；min-max 标准化；距离和 χ² |
| 数据仓库 | 识别事实/维/度量；画星型模式；从基本/顶点方体列出 OLAP 操作 |
| 频繁模式 | 过滤低支持项；建 FP-tree；写条件模式基并产生频繁项集 |
| 关联规则 | 计算 support、confidence、lift、all-confidence 并解释正/负/独立关系 |
| 分类 | 计算熵、信息增益/Gini；执行朴素贝叶斯或一次感知器更新 |
| 聚类 | 执行一轮 K-means/K-medoids，分析初始化和异常值 |
| 设计题 | 为 Web、货运或反欺诈问题确定对象、维度、特征、方法和评价 |

所有计算都要写清分母、阈值、候选集合和剪枝理由；FP-tree 只画最终树而不记录排序与计数，难以发现错误。

## 🔍 学习方法

1. 建立术语对照表，特别区分数据仓库/数据库、分类/聚类、频繁/闭合/极大项集。
2. 用同一个小事务集分别手算 Apriori 与 FP-growth，比较它们减少扫描或候选的方式。
3. 用同一分类表计算 entropy、gain ratio 和 Gini，观察属性排序是否变化。
4. 为每种兴趣度构造“高支持但无关联”或“低支持但强关联”的反例。
5. 画数据立方体时明确层次和聚合函数是否可加。
6. 对分类/聚类结果同时考虑效果、可解释性、计算成本和数据偏差。

## ✅ 完成标准

完成本项目后，学生应能够：

1. 从业务问题设计数据挖掘流程，说明每一步输入、输出和风险。
2. 完成常见统计、分箱、归一化、距离和关联检验手算。
3. 设计星型模式，并从查询需求写出相应 OLAP 操作。
4. 从事务表构建 FP-tree，产生频繁/闭合/极大模式与强关联规则。
5. 解释并手算一种分类方法、属性选择指标和一种聚类方法。
6. 区分 support、confidence、lift 等指标，并识别误导性关联。
7. 面对新数据场景时，选择合适方法和评价标准，同时说明可解释性与局限。
