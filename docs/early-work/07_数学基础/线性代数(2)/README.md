_依据本目录的讨论课、习题答案和历年试卷整理，从多项式与标准形推进到内积空间、伴随算子和复线性代数_

---

## 📋 课程定位

线性代数（2）在第一阶段的向量空间、线性映射和特征理论之上，研究线性算子的更精细分类与几何结构。本地样题和讨论课涉及多项式除法与因式分解、不变子空间、Jordan 标准形、正交/酉结构、伴随与 Hermite 矩阵、双线性型以及线性方程的广义求解。

这门课的核心是“选择合适结构和基来简化算子”。计算必须服务于不变量、标准形和空间分解，而不是孤立地背矩阵公式。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 线性代数二学习主线
    accDescr: 从多项式代数和算子不变量出发，经循环子空间与标准形进入内积空间、伴随和正规算子，最后处理双线性结构与综合分类

    polynomial[多项式代数] --> invariant[不变子空间] --> minimal[最小多项式] --> jordan[Jordan 与标准形] --> inner_product[内积与正交补] --> adjoint[伴随与 Hermite] --> normal[正规算子谱定理] --> forms[双线性结构]
~~~

1. 先补齐多项式 Euclid 算法、互素和因式分解，为算子多项式打底
2. 学习不变子空间、循环子空间、限制和直和分解
3. 用最小多项式和广义特征空间理解不可对角化算子
4. 构造 Jordan 链和相似变换，再了解有理标准形背后的模结构思想
5. 进入实/复内积空间、正交补、投影和酉算子
6. 最后学习伴随、Hermite/正规算子谱定理和双线性型

## ⚙️ 练习与实践

- 多项式题保留除法、余式与 Bezout 组合，结果用代回或整除关系验证
- Jordan 题同时核对特征多项式、最小多项式、块数、块大小、秩与核维数
- 构造广义特征向量链时逐级验证 `(A-λI)v_{k+1}=v_k`
- 复内积计算明确哪一变量共轭线性，避免沿用实数点积公式
- 伴随和 Hermite 题用内积定义与共轭转置两种方式交叉验证
- 标准形计算完成后用迹、行列式和最小多项式做一致性检查

## 🔍 结构与分类方法

- 特征多项式给出代数重数，最小多项式给出最大 Jordan 块，核维数序列给出块分布
- 不变子空间是分块化算子的关键；直和分解比直接求大矩阵幂更能揭示结构
- 实正交、复酉、Hermite、正规等概念依赖底域和内积，先确认空间再引用谱定理
- 投影算子满足幂等性，但只有正交投影还满足自伴；不要把两者混同
- 每个分类结论都区分“相似”“酉相似”和“合同”，它们保留的不变量不同
