## 📋 课程定位

复变函数把微积分、级数和几何映射统一到复平面中。它既训练严格的解析证明，也提供计算实积分、研究解析延拓和构造区域映射的工具。本目录同时包含多位教师的历年卷、复习材料和一组以分式线性映射为主的作业答案，适合用来建立“解析—积分—级数—奇点—映射”的知识网络。

本地样卷明确出现 Cauchy–Riemann 条件、调和函数、复积分、Abel 定理与收敛半径、分式线性映射和上半平面自映射；其他试卷与答案可用于补足 Cauchy 积分、Laurent 展开、留数计算等常规核心内容。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 复变函数学习主线
    accDescr: 从复数与解析性出发，经复积分和级数进入奇点与留数，最后完成共形映射和综合应用

    complex_plane[复数与初等函数] --> analytic[解析性与调和性] --> contour[复积分] --> cauchy[Cauchy 理论] --> series[级数与展开] --> singularity[奇点与留数] --> mapping[共形映射] --> synthesis[综合应用]
~~~

1. 先解决复对数、复幂和辐角的多值性，形成“支路与割线”意识
2. 用 Cauchy–Riemann 条件连接复可微、解析性与调和函数
3. 掌握曲线积分参数化，再学习 Cauchy 定理、积分公式及其推论
4. 学习幂级数、Taylor/Laurent 展开，并把展开区域写成圆盘或圆环
5. 用 Laurent 主部分类奇点，进而学习留数定理和实积分
6. 最后学习分式线性映射、基本映射的复合，以及典型区域之间的共形映射

## ⚙️ 练习与实践

- 解析性题固定完成四步：写实虚部、求偏导、检查 Cauchy–Riemann、确认邻域条件
- 每个复积分先画路径和奇点，再选择原函数、Cauchy 公式或留数定理
- 每个 Laurent 展开同时写出中心、环域和使用的几何级数形式
- 留数题至少掌握极限法、导数公式和 Laurent 系数法，并交叉验证简单极点
- 映射题先画源区域边界，逐个跟踪基本映射，再用测试点判断哪一侧被映到目标内部
- 真题训练中把“计算正确”和“使用定理的条件完整”分开评分

## 🔍 学习与证明方法

- 把解析函数看成局部线性变换：非零导数同时给出伸缩和旋转，从而理解保角性
- 把 Cauchy 理论作为主枢纽：解析性推出积分性质，积分公式又推出无穷可微和级数展开
- 处理多值函数时，先写出主值或所选支路，再进行代数运算
- 处理映射时同时使用代数法和几何法：代数法验证公式，几何法检查圆线、方向与内部
- 每次引用定理都标出区域是否单连通、曲线是否闭合、函数是否在曲线内外解析
