# 初等数论学习指南

_依据本目录中的复习材料、期中期末试题与参考答案整理，目标是建立可证明、可计算、可迁移的整数理论基础_

---

## 📋 课程定位

初等数论研究整数的整除、同余和算术结构，是密码学、离散数学与代数算法的重要基础。本目录以历年考试和一份综合复习材料为主，适合在完成教材学习后用于核对定理、训练证明和模拟考试，不宜把真题编号直接当成完整课程目录。

本地试题明确覆盖良序原理、带余除法、中国剩余定理、Fermat 小定理、Euler 函数、群中的 Lagrange 定理、元素的阶、Euler 判别法和 Legendre 符号。学习时应同时掌握定理的条件、证明思路和典型计算，而不是只记结论。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 初等数论学习主线
    accDescr: 从整数整除与同余基础，经算术函数和群论方法，进入二次剩余，最后用综合证明和真题完成闭环

    divisibility[整数与整除] --> congruence[同余与方程] --> crt[中国剩余定理] --> arithmetic[算术函数] --> group_order[阶与群方法] --> quadratic[二次剩余] --> synthesis[综合证明]
~~~

1. 先用带余除法和 Euclid 算法建立“存在、唯一、可计算”的基本框架
2. 学习线性同余方程和中国剩余定理，始终写清模数条件与全部解
3. 由素因子分解推导 Euler 函数等算术函数的公式和积性
4. 把剩余类中的乘法放入有限群语言，理解阶、Lagrange、Fermat 与 Euler 定理之间的关系
5. 学习二次剩余、Euler 判别法、Legendre 符号和二次互反律
6. 最后按“定义题—计算题—定理证明—综合题”完成真题训练

## ⚙️ 练习与实践

- 每个核心定理至少完成三件事：准确复述、独立证明、设计一个反例说明条件不可删
- 同余计算必须保留可解性判断、模逆元或 Bézout 构造、通解形式和代回验证
- 为 Fermat/Euler 定理、阶和二次剩余各整理一张“适用条件—结论—常见误用”卡片
- 对 Legendre 符号计算保留每次互反、补充律和模化简步骤，避免只写最终符号
- 真题至少做两轮：第一轮按主题拆题，第二轮限时完成并按证明缺口复盘

## 🔍 学习与证明方法

- 遇到“最小反例”或整数存在性，优先考虑良序原理；遇到递推式性质，再考虑归纳法
- 遇到整除与线性表示，优先转化为最大公因数和 Bézout 等式
- 遇到模幂问题，先确认底数是否为单位，再使用群的阶或 Euler/Fermat 定理
- 遇到“对所有整数”的命题，主动检查负数、零、模数为 1、互素性缺失等边界
- 证明完成后做逆向检查：每一步用了什么条件，结论是否比题目更强，是否遗漏唯一性
