# 数学实验学习指南

_依据本目录的十次 MATLAB/LINGO 实验报告、考试试题和回归分析讲义整理，贯通建模、计算、验证与报告表达_

---

## 📋 课程定位

数学实验不是单纯的软件操作课，而是把微积分、线性代数、优化和概率统计用于实际问题的综合训练。本目录十次实验依次覆盖插值与积分、常微分方程、线性/非线性方程、连续与整数优化、Monte Carlo、统计推断和回归分析；试题还要求在有限时间内选择工具、解释参数并判断结果。

学习闭环应是：理解情境，提出假设，建立模型，选择算法，写出可复现实验，验证数值结果，解释误差与局限。仅能调用 MATLAB 或 LINGO 命令并不算掌握。

~~~mermaid

    tools[计算工具与数据] --> approximation[插值积分与 ODE] --> equations[线性非线性方程] --> optimization[连续优化建模] --> integer[整数规划] --> probability[Monte Carlo] --> statistics[统计与回归] --> report[验证与报告]
~~~

1. 先掌握 MATLAB 的矩阵化表达、函数封装、绘图和随机种子管理
2. 通过实验 1—2 学会把数学公式转成算法，并用已知解或加密步长验证
3. 通过实验 3 理解条件数、收敛性、初值和参数敏感性
4. 通过实验 4—7 建立优化变量、目标函数、约束和求解器结果之间的对应
5. 通过实验 8—10 进入 Monte Carlo、统计推断和回归诊断
6. 最后按统一模板重做一个跨主题项目，形成完整的模型、代码、结果和反思

## ⚙️ 实验工作流

1. **问题定义**：明确输入、输出、单位、决策变量和评价指标
2. **模型假设**：写出简化条件及其可能造成的偏差
3. **算法设计**：给出公式、伪代码、收敛/终止条件和复杂度意识
4. **程序实现**：固定随机种子，保留参数，避免把中间结果手工写入程序
5. **结果验证**：使用解析解、极端案例、替代算法或步长加密交叉检查
6. **敏感性分析**：改变初值、步长、噪声、约束或样本量，解释结果变化
7. **报告表达**：图表有标题、坐标、单位和结论，区分观测事实与主观解释

## 🔍 建模与分析方法

- 先做量纲和数量级检查，常能发现比程序错误更隐蔽的建模问题
- 求解器返回“成功”只说明满足其停止标准，不自动保证模型正确或全局最优
- 比较算法时同时记录精度、迭代次数、运行时间、稳定性和实现成本
- 回归模型先看散点图和残差，再看系数、置信区间、p 值与决定系数
- Monte Carlo 结果必须报告样本量和波动；一次随机输出不能代表稳定结论
- 报告中保留失败尝试及其原因，它们是理解算法边界的重要证据

- 本目录主要保存完整实验报告，嵌入代码可用于理解，但不应直接复制为自己的作业

- 不同年份对允许的语言和软件有不同要求；本目录报告偏 MATLAB/LINGO，而当前要求须另行确认
