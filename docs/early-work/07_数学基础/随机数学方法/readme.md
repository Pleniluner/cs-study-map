## 📋 课程定位

随机数学方法比基础概率统计更强调随机过程与分布变换工具。本目录样卷从条件概率、随机变量和联合分布起步，继续考查特征函数、随机游走、Poisson 过程、Brown 运动以及依分布收敛，因此学习时既要巩固概率计算，也要建立“有限维随机变量—离散时间过程—连续时间过程”的连接。

本目录只有一套样卷及简版答案，适合用来确认知识边界和作最终自测，不能替代教材、课堂讲义与分章节练习。

2. 学习特征函数及其对独立和、唯一性和极限的表达能力

6. 最后学习 Brown 运动的定义、有限维正态性、协方差与 Brown 桥

## 🔍 随机过程思维

- 随机变量描述一个时刻的结果，随机过程描述一族按时间索引的随机变量
- 独立增量、平稳增量和样本路径连续性是不同性质，分别核对
- 条件于终点后，过程的均值与协方差会改变；Brown 桥不是普通 Brown 运动
- 特征函数法的优势是把独立随机变量之和转化为乘法，并便于处理极限
- 过程题中的条件信息通常改变剩余区间分布，先重写信息再计算
