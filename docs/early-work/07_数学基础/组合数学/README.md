# 组合数学学习指南

_依据本目录 2013—2017 年期末试卷与答案整理，覆盖计数、递推、母函数、群作用、图结构与课程特有的线性规划综合题_

---

## 📋 课程定位

组合数学研究有限结构的计数、构造和存在性，是算法分析、编码、概率、图论和离散优化的重要工具。本目录虽只有六份期末资料，但题型跨度很大：格路与反射、容斥、递推、母函数、Fibonacci 模周期、设计上界、Burnside/Pólya 计数、多面体对称群，以及线性规划和单纯形法。

学习时应把同一道题连接到多个视角：直接计数、递推、生成函数、群作用或图模型。能列出答案公式只是起点，还要解释为什么不重不漏。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 组合数学学习主线
    accDescr: 从基本计数和二项式恒等式出发，经容斥、格路和递推进入生成函数，再学习群作用计数、结构上界与离散优化

    counting[基本计数原理] --> identities[二项式与双计数] --> inclusion[容斥与筛法] --> lattice[格路与反射] --> recurrence[递推与状态] --> generating[生成函数] --> group_actions[群作用计数] --> optimization[结构与优化]
~~~

1. 先用基本计数、二项式系数和双计数建立“不重不漏”的表达习惯
2. 学习容斥、错排和整除筛选，掌握交集层次的符号组织
3. 用格路和反射原理处理前缀限制、比分领先和 Catalan 型问题
4. 学习递推状态设计、初值和特征根解法
5. 用普通/指数生成函数统一递推、标号对象和出现次数限制
6. 最后学习 Burnside/Pólya、多面体对称、结构上界和线性规划

## ⚙️ 练习与实践

- 每道题先写“被计数对象”和“等价关系”，再选择排列组合公式
- 容斥题列出全集、坏事件和所有必要交集，使用小规模枚举核验
- 递推题把末端形态或边界缺口设为状态，并给出足够初值
- 生成函数题标明普通还是指数型，并在最终答案中明确提取哪个系数
- Burnside/Pólya 题按群元素类型建表：数量、循环结构、每类不动配置数
- 单纯形题从标准型、基变量和检验数开始，保留每次枢轴选择与终止依据

## 🔍 组合思维方法

- 双计数的关键是构造同一个集合的两种计数方式，而不是只做代数变形
- 递推需要“状态闭合”：下一步所需信息必须全部包含在当前状态中
- 生成函数是系数编码工具；代数操作必须能解释为组合构造
- 群作用计数先确定哪些配置视为等价，再讨论对称群和不动点
- 上界证明与构造同样重要：计数资源消耗给上界，显式方案给可达性
