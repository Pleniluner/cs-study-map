# 微积分 A（2）学习指南

_依据本目录的习题课、章节作业答案、期中期末样卷整理，从多元微分贯通到重积分、向量分析、级数与 Fourier 展开_

---

## 📋 课程定位

微积分 A（2）把一元分析推广到多变量、空间几何和无穷级数。本地期中样卷集中在多元极限、偏导、隐函数、Taylor 展开、极值和广义积分；期末样卷进一步覆盖重积分、曲线/曲面积分、Green/Gauss/Stokes 型公式、幂级数和 Fourier 级数。

课程难点来自表示形式的切换：坐标、参数化、几何区域、向量场和级数需要相互翻译。学习时应把“画区域—选坐标—写边界—检查方向”训练成固定流程。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 微积分二学习主线
    accDescr: 从多元极限与微分出发，经隐函数和极值进入重积分与向量分析，最后学习无穷级数、幂级数和 Fourier 展开

    multivariable_limit[多元极限与连续] --> differential[全微分与梯度] --> implicit[隐函数与极值] --> multiple_integrals[重积分与换元] --> line_surface[曲线曲面积分] --> vector_calculus[向量分析公式] --> power_series[级数与幂级数] --> fourier[Fourier 展开]
~~~

1. 先区分偏导存在、连续和可微，熟练多元链式法则与 Jacobian
2. 学习方向导数、梯度、隐函数和多元 Taylor，再处理极值与 Lagrange 乘子
3. 进入二重/三重积分，训练区域分解和极、柱、球坐标换元
4. 学习曲线/曲面积分的参数化、方向和法向
5. 以 Green、Gauss、Stokes 公式统一局部微分量与整体积分
6. 最后学习数项/函数项级数、幂级数与 Fourier 级数

## ⚙️ 练习与实践

- 多元极限题至少尝试两条路径寻找反例；要证明存在时使用统一估计
- 可微性题按“偏导—连续—线性主部—余项”检查，不用偏导存在直接推出可微
- 重积分先画投影区域，再决定积分次序和坐标系，换元时写 Jacobian 绝对值
- 第二类曲线/曲面积分明确方向或侧，应用大公式前画出边界定向
- 级数题先判收敛域和端点，再做逐项求导、积分或代值
- Fourier 展开同时计算系数并判断跳跃点、端点的收敛值

## 🔍 几何与分析方法

- 梯度是最速上升方向也是等值面的法向；把代数公式和几何意义同时记忆
- 坐标变换的核心是区域简化，Jacobian 反映面积或体积缩放
- Green/Gauss/Stokes 公式使用前核对光滑性、区域、边界闭合及定向
- 条件极值需同时检查正则点、约束退化点和边界端点
- 函数项级数中的逐项操作依赖一致收敛等条件，不能照搬有限和运算
