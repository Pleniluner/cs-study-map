## 📋 课程定位

数值分析研究如何在有限精度计算机上可靠地求近似解。课程的主角不是某个软件，而是误差如何产生、算法为何收敛、结果是否稳定，以及理论公式怎样变成可验证的程序。本目录包含 276 个文件，是本单元中实践材料最丰富的一门课：既有实验要求和历年卷，也有 C++、MATLAB、报告、输入输出和可执行文件。

实验指导明确要求理解算法全过程、如实记录数据并比较理论结果。学习时应优先阅读题目和指导，自行实现后再参考历届代码与报告。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 数值分析学习主线
    accDescr: 从误差与浮点计算出发，依次学习插值拟合、积分、线性系统、非线性求根、特征值和常微分方程，最终完成算法验证

    error[误差与浮点数] --> interpolation[插值与拟合] --> quadrature[数值积分] --> linear_systems[线性方程组] --> nonlinear[非线性求根] --> eigenvalues[特征值计算] --> ode[常微分方程] --> validation[稳定性与验证]
~~~

1. 先建立误差、条件数、稳定性和停止准则的统一语言
2. 用插值和最小二乘理解“精确通过数据”与“整体逼近数据”的差别
3. 学习数值积分的代数精度、余项、复合与外推
4. 进入线性系统，先掌握带主元消元和分解，再学习 Jacobi/GS/SOR
5. 学习非线性求根和特征值迭代，统一理解初值、谱和收敛速度
6. 最后学习 ODE 单步法、局部/整体误差与绝对稳定域

## ⚙️ 实验与编程方法

- 每项算法先写数学伪代码，再自己实现核心步骤，避免只调用库函数得到答案
- 同时记录理论误差界、实际误差、残差和迭代次数；残差小不等于解误差小
- 使用解析解、制造解或高精度参考值建立自动校验
- 对步长、阶数、节点、松弛因子和初值做参数扫描，绘制误差或收敛曲线
- 对病态矩阵加入微小扰动，观察输入误差如何被条件数放大
- 报告必须包含算法、程序、数据、结果比较和失败/异常分析

## 🔍 数值思维方法

- 先问问题是否病态，再问算法是否稳定；两者是不同层次
- 比较算法不能只看理论阶，还要考虑每步成本、常数、内存和可并行性
- 迭代法停止时同时检查相邻迭代差与残差，阈值应与数据尺度匹配
- 高阶方法并非永远更好；舍入误差、非光滑性和稳定域会改变实际效果
- 实验结论应说明适用数据和参数范围，不把一次运行推广为普遍定理

## ⚠️ 资料边界与注意事项

- 历届代码与报告来自不同年份，算法题、允许语言和提交规则并不完全一致
- 目录中有 `.exe`、`.bat`、压缩包和临时 Office 文件；学习只需阅读源代码和报告，不必运行来历不明的可执行文件
- 多份报告和代码内容重复，选择一套作主线、另一套作交叉核验即可
- 旧试题文本存在编码乱码，公式和矩阵应查看 PDF 或原始页面
- 有些实验明确限制直接使用 MATLAB/Python 求解核心算法，当前课程规则须另行确认
