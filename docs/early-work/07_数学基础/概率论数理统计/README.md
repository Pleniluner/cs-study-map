# 概率论与数理统计学习指南

_依据本目录的考试要求、三组习题课、历年样卷与参考解答整理，从随机现象建模贯通到统计推断_

---

## 📋 课程定位

这门课分成两条连续主线：概率论从随机试验出发研究分布、数字特征和极限定理；数理统计以样本为依据，对未知总体参数进行估计和检验。本目录资料非常适合训练，但大部分位于 `exam` 下，学习顺序应由概念和例题驱动，再用习题课与真题闭环。

目录中的考试要求给出了较完整的范围，历年题进一步出现联合分布、条件期望、正态向量、最大似然、置信区间和假设检验。不同年份对 Poisson 过程等内容的要求可能不同，必须以当前课程说明为准。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 概率统计学习主线
    accDescr: 从事件与条件概率出发，经过随机变量、联合分布、数字特征和极限定理，进入抽样分布、参数估计与假设检验

    events[事件与条件概率] --> variables[随机变量与分布] --> joint[联合与条件分布] --> moments[数字特征] --> limits[极限定理] --> sampling[抽样分布] --> estimation[参数估计] --> testing[区间与检验]
~~~

1. 用树图、集合图和条件概率公式解决事件层面的建模
2. 系统掌握常见分布的定义、期望方差、无记忆性和相互关系
3. 进入二维随机变量，训练积分区域、边缘化、条件化和变量变换
4. 用期望、协方差和条件期望建立统一计算语言
5. 学习大数定律与中心极限定理，区分精确分布和渐近近似
6. 由样本统计量和三大抽样分布进入点估计、区间估计与假设检验

## ⚙️ 练习与实践

- 每道概率题先写样本空间或随机变量，再写事件，最后才代公式
- 二维连续型题先画支持域；换元时同时处理像域、Jacobian 和多对一情况
- 为 Bernoulli、二项、几何、Poisson、均匀、指数、正态、卡方、t、F 建立分布卡片
- 估计题固定写出似然函数、参数空间、求极值过程，再检查边界点和估计性质
- 检验题固定写六项：原假设、备择假设、统计量、零假设分布、拒绝域或 p 值、语境结论
- 每完成一组习题课，用无答案 Set C 进行一次闭卷迁移测试

## 🔍 学习与推断方法

- 条件概率的核心是“更新样本空间”；独立性必须由乘法关系验证，不能凭直觉判断
- 随机变量变换优先使用分布函数法，单调一一时再用密度变换公式
- 条件期望既是随机变量也是最佳均方预测工具，先确认条件对象再计算
- 正态向量中“不相关推出独立”有分布前提，不能推广到任意随机变量
- 统计结论描述的是证据强弱，不写“接受原假设为真”；应写“在给定显著性水平下是否拒绝”
