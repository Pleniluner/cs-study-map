# 微积分 A（1）学习指南

_依据本目录七次习题课、期中期末试题和常微分方程材料整理，覆盖一元函数极限、微分、积分及初等微分方程_

---

## 📋 课程定位

微积分 A（1）建立连续变化的基本语言，是概率、数值分析、优化和后续多元微积分的先修课。本目录从第 1 次习题课的上确界、数列极限出发，到第 7 次习题课的一阶微分方程和物理应用；期末样题还系统考查不定/定积分、几何应用以及一阶、二阶微分方程。

学习时必须同时发展三种能力：用定义和定理证明，用技巧完成计算，用函数/微分方程建立模型。只刷计算题会在极限定义、收敛性和证明题上留下明显缺口。

## 🎯 必须掌握的能力

| 模块 | 应掌握的知识 | 达标表现 |
| --- | --- | --- |
| 实数与极限 | 上下确界、数列极限、单调有界、子列、Cauchy 思想 | 能用定义或基本定理证明收敛 |
| 函数极限与连续 | 极限运算、无穷小、连续性、间值与最值性质 | 能判断间断并处理参数极限 |
| 一元微分 | 导数、微分、中值定理、Taylor 展开、单调与凹凸 | 能由导数完成函数全局分析 |
| 不定积分 | 换元、分部、部分分式、三角与有理化技巧 | 能选择方法并回代检查 |
| 定积分 | 可积性、微积分基本定理、变限积分、参数处理 | 能把积分与导数互相转换 |
| 积分应用 | 面积、体积、弧长、旋转曲面、物理量 | 能从几何或物理情境建立积分 |
| 广义积分 | 无穷区间与瑕积分、比较和极限判别 | 能说明收敛而非只计算形式原函数 |
| 微分方程 | 可分离、齐次、一阶线性、Bernoulli、高阶常系数方程组 | 能由初值确定解并解释模型 |

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 微积分一学习主线
    accDescr: 从实数完备性和数列极限出发，经连续与微分进入积分理论和几何应用，最后学习广义积分与常微分方程

    real_numbers[实数与数列极限] --> continuity[函数极限与连续] --> derivative[导数与中值定理] --> taylor[Taylor 与函数分析] --> integral[不定与定积分] --> applications[积分应用] --> improper[广义积分] --> ode[常微分方程]
~~~

1. 先掌握上确界、数列收敛与单调有界原理，训练定义证明
2. 由数列极限过渡到函数极限和连续性，建立局部与整体性质的联系
3. 学习导数、中值定理和 Taylor 展开，用导数研究函数形态与误差
4. 系统练习不定积分技巧，再用微积分基本定理建立定积分理论
5. 完成面积、体积、弧长和物理应用，明确变量、微元与区间
6. 最后学习广义积分收敛和常微分方程，把分析工具用于动态模型

## ⚙️ 练习与实践

- 极限证明必须明确给定量、待选阈值和不等式链，避免只写“显然趋于”
- 函数分析题按定义域、奇偶/周期、零点、单调、极值、凹凸、渐近线依次检查
- 积分计算后用求导验算；定积分还要检查符号、对称性和数量级
- 几何应用先画图、选变量和切片方向，再写微元与积分上下限
- ODE 题先识别类型，再求通解、代初值并检查解的定义区间
- 习题课题目先闭卷做，答案只用于比较关键变形和证明结构

## 🔍 分析与建模方法

- 把定义、定理条件和计算技巧分层学习：定义用于证明，定理用于搭桥，技巧用于缩短计算
- 中值定理是从局部导数走向整体函数性质的核心，使用时写出连续与可导区间
- Taylor 展开必须同时关注展开点、阶数和余项，而不是只背多项式
- 广义积分先判断收敛，再谈积分值；形式上的换元不能绕过收敛性
- 微分方程模型要检查单位、初始条件和解在现实范围内是否合理
