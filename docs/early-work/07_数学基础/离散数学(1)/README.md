## 📋 课程定位

离散数学（1）为计算机科学建立形式语言和离散结构基础。课程从命题逻辑、谓词逻辑出发，进入集合、关系、函数、基数和偏序结构，训练把自然语言精确翻译成符号并从定义出发证明结论的能力。

本目录的 2016 年期末卷覆盖联结词完备集、量词、集合运算、关系闭包、等价关系、偏序与 Hasse 图、无穷集合、容斥和形式化证明；周作业及前束范式专题可用于补足证明细节。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 离散数学一学习主线
    accDescr: 从命题逻辑和谓词逻辑出发，经过集合、关系与函数，进入等价关系、偏序和无穷集合，并以形式证明完成闭环

    proposition[命题逻辑] --> predicate[谓词逻辑] --> sets[集合与计数] --> relations[关系及闭包] --> functions[函数与等势] --> order[等价与偏序] --> infinity[基数与无穷] --> proof[综合证明]
~~~

1. 用真值表和等值变换掌握命题逻辑，再训练主析取/主合取范式
2. 进入谓词逻辑，先固定论域，再处理量词否定、形式化和推理规则
3. 学习集合代数、笛卡尔积、幂集、容斥与基本计数
4. 系统掌握关系的性质、闭包、复合和矩阵/有向图表示
5. 由等价关系进入划分，由函数进入单射、满射、双射与等势
6. 学习偏序、Hasse 图、链与反链，最后补充可数性和基数问题

## ⚙️ 练习与实践

- 自然语言形式化时先写论域和谓词含义，再翻译量词与联结词
- 范式题同时用等值变换和真值表校验，避免漏掉极小项或极大项
- 关系性质题对每个性质分别证明或给反例，不用图形直觉代替定义
- 集合恒等式至少掌握元素追踪法和集合代数法两种证明方式
- Hasse 图先去掉自环和传递边，再识别极大/极小、最大/最小、链与反链
- 每周作业做完后，将错误改写成一个“最小反例”或一条准确的定义判断题

## 🔍 学习与证明方法

- 语义层面回答“公式何时为真”，语法层面回答“可按什么规则推出”，两者不要混淆
- 量词变换时检查变量捕获；必要时先做约束变元改名
- 证明关系具有某性质时从任意元素开始；证明不具有某性质时只需一个合法反例
- 处理无穷集合时优先构造显式双射或两个方向的单射，不依赖“看起来一样多”
- 对“若且唯若”命题分成充分性和必要性两个方向书写
