## 📋 课程定位

线性代数（1）为算法、机器学习、图形学、数值计算和量子计算提供共同语言。课程不应被压缩成矩阵计算技巧：矩阵只是线性映射在选定基下的表示，秩、特征值和正交结构都需要回到空间与变换理解。

本地 2013 样题覆盖秩、特征值、基变换、相似、空间几何、线性方程组、初等变换、二次曲面、实对称矩阵、线性变换和正定性；完整讲义为扫描 PDF，历年卷和 MIT 试题适合用于迁移训练。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 线性代数一学习主线
    accDescr: 从消元与线性方程组出发，经向量空间、线性映射和基变换进入特征理论，再学习正交结构、对称矩阵与二次型

    elimination[消元与方程组] --> vector_spaces[向量空间与基] --> linear_maps[线性映射] --> coordinates[矩阵与基变换] --> eigen[特征值与相似] --> orthogonal[正交与投影] --> symmetric[对称矩阵] --> quadratic[二次型与几何]
~~~

1. 从消元出发，理解秩、主元、自由变量和解空间维数
2. 抽象出向量空间、子空间、基与维数，并用坐标把抽象对象数值化
3. 学习线性映射的核、像和秩零化度，再理解矩阵表示与基变换
4. 学习特征值、相似和对角化，把迭代与线性动力系统看成谱问题
5. 引入内积、正交化、投影和最小二乘
6. 最后学习实对称矩阵谱定理、正定性、二次型与空间几何

## ⚙️ 练习与实践

- 方程组既做行消元，也写出“一个特解加齐次解空间”的结构表达
- 每个抽象空间题都尝试给出一组基和维数，检查生成与线性无关
- 基变换题画清“向量不变、坐标变化、表示矩阵变化”的关系
- 特征题先求特征空间维数，再判断是否有足够特征向量对角化
- 投影和最小二乘题用正交条件或正规方程验证结果
- 二次型题在计算标准形后解释其正负性和几何类型

## 🔍 结构化理解方法

- 行变换保留方程组解集关系但不保留全部谱信息，使用前确认目标
- 相似矩阵表示同一线性变换的不同基；合同矩阵描述二次型坐标变换，两者不要混淆
- 秩既是主元数、列空间维数也是像空间维数，用多种视角交叉检查
- 对角化的价值是把耦合变换分解为沿特征方向的独立伸缩
- 正交基使坐标、投影和长度计算稳定简洁，应优先使用
