# 离散数学（2）学习指南

_依据本目录的图论习题课、历年试卷和图论应用报告整理，覆盖图结构、网络算法、群与置换的后续课程主线_

---

## 📋 课程定位

离散数学（2）把离散结构从逻辑与集合推进到图论和代数结构。本目录试题明确要求图的矩阵表示、回路与平面图、对偶图、最大流、旅行商近似、Kruskal 最小生成树，以及群、置换和循环群证明；应用报告还展示了 Delaunay 三角剖分、Voronoi 图与最小生成树之间的联系。

学习目标不是记住算法名称，而是能从定义证明结构性质、手工执行算法、说明正确性与复杂度，并判断模型是否满足算法前提。

## 🔗 全阶段学习顺序

~~~mermaid
flowchart LR
    accTitle: 离散数学二学习主线
    accDescr: 从图的表示和连通性出发，依次学习树、平面图、图上优化与网络流，再进入群和置换，最终完成应用建模

    graph_model[图与矩阵表示] --> connectivity[路与连通性] --> trees[树与生成树] --> planar[平面图与对偶] --> optimization[最短路与优化] --> flow[网络流] --> groups[群与置换] --> applications[图论应用]
~~~

1. 先统一图的术语、矩阵表示和度数计数公式
2. 学习路、回路和连通结构，用反证与奇偶性处理存在性问题
3. 掌握树的等价性质，再进入 Kruskal/Prim 等生成树算法
4. 学习平面图、Euler 公式和对偶图，练习从嵌入而非抽象图构造对偶
5. 学习最短路、旅行商启发式与网络流，区分问题、算法与最优性证书
6. 最后学习群、子群、循环群和置换，并用应用报告完成建模迁移

## ⚙️ 练习与实践

- 每个图算法都保留“输入前提—维护不变量—终止条件—输出证书”四部分
- 手算 Kruskal 时记录边排序和并查集合并；手算最大流时记录残量网络与增广量
- 对平面图题先固定嵌入，再标面并构造对偶，避免只凭邻接关系画图
- 对旅行商最近邻算法明确起点与平局规则，并说明结果不保证全局最优
- 群论题先验证封闭性、单位元、逆元，再使用子群判别法
- 应用报告按“问题定义—图模型—性质—算法—复杂度—验证”重写一遍摘要

## 🔍 学习与证明方法

- 图论证明优先寻找度数和、连通分量数、边数与顶点数等不变量
- 贪心算法不能只展示运行结果，必须说明局部选择为何不会破坏某个最优解
- 最大流的最终答案应同时给出同容量的割，形成上界与下界相等的证明
- 置换复合要固定从右到左或课程规定的约定，并用循环分解复核
- 抽象代数结论先检查运算和集合，不能把数的直觉直接迁移到任意群
