# 记录自己的学习

[返回教材](textbook/index.md)

把下面的模板复制到本机 `.local/study-log.md`。这一目录被 Git 忽略，自己的进度、错题和想法留在本机即可。

第一次试学可先读[三章试学指南](study-guide.md)，读完后做[综合练习](unit-01-review.md)。已安装项目时，也可以按[运行说明](usage.md#study)用 `study` 命令保存状态和短笔记。章节页面中的复选框不会自动写入个人进度。

不要只记“看懂了”。先遮住解答重新推导，再改变一个数值或初始条件。如果解释不通，把疑问写成一句可以验证的问题，后续让教材围绕这些卡点补充说明。
